**Docker = a way to package your app + everything it needs into a portable box.**

* Your code ✅
* Python version ✅
* Libraries ✅
* OS dependencies ✅

➡️ That box = **container**
➡️ Blueprint for the box = **image**

So instead of:

> “it works on my machine…”

You get:

> “it works *everywhere*.”

# 🧪 Example Lesson (so you see the style)

## 01_run_first_container.md

```md
# Run Your First Container (2 min)

## Goal
Run Python inside Docker without installing Python.

## Command
docker run --rm python:3.11 python -c "print('Hello from Docker')"

## What happened?
- Docker pulled an image
- Started a container
- Ran your command
- Deleted container (--rm)

## Why this matters
You just ran Python WITHOUT installing it.

That’s the whole game.
```
