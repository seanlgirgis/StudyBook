# 🚀 Step-by-step: Run 03A (Compose stack)

## 1. Go to the correct folder

```powershell
cd D:\Workarea\StudyBook\tutorials\36_docker\03a_compose_stack
```

---

## 2. Create `.env` (required)

You already saw this before, but do it inside THIS folder:

```powershell
copy .env.example .env
```

Check it:

```powershell
type .env
```

---

## 3. Start the stack

```powershell
docker compose up --build
```

👉 What happens:

* Builds pipeline image (from this folder)
* Starts:

  * `pipeline` container
  * `postgres` container
* Creates:

  * network
  * volume

---

## 4. Watch logs (important)

You should see:

```text
postgres-1  | database system is ready
pipeline-1  | connected to postgres
pipeline-1  | wrote row to pipeline_runs
```

---

## 5. Verify from another terminal (DO THIS)

Open new PowerShell window:

```powershell
cd D:\Workarea\StudyBook\tutorials\36_docker\03a_compose_stack
```

Run:

```powershell
docker compose ps
```

You should see both containers running.

---

## 6. Query Postgres (this is the magic moment)

```powershell
docker compose exec postgres psql -U pipeline -d studybook -c "SELECT * FROM pipeline_runs;"
```

👉 This proves:

* pipeline → wrote data
* postgres → stored it

---

# 🧠 What just happened (simple)

```text
pipeline container → connects → postgres container → writes row
```

Inside Docker network:

```text
hostname = postgres
port     = 5432
```

No localhost. No IPs. Just service name.

---

# 🛑 How to stop it

In the terminal where it's running:

```powershell
Ctrl + C
```

Then clean shutdown:

```powershell
docker compose down
```
