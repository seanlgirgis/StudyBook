# 🔍 What “deploy” means in Docker terms

Let’s be precise:

| Action              | What it does                              |
| ------------------- | ----------------------------------------- |
| `docker build`      | Creates an **image**                      |
| `docker run`        | Starts a **container (running thing)**    |
| `docker compose up` | Starts **multiple containers (a system)** |
