# 🧠 What your pipeline would actually do

Inside your container, Python would connect to Postgres like this:

```python
import os
import psycopg2

conn = psycopg2.connect(
    host=os.getenv("DB_HOST", "postgres"),
    port=int(os.getenv("DB_PORT", 5432)),
    dbname=os.getenv("DB_NAME", "studybook"),
    user=os.getenv("DB_USER", "pipeline"),
    password=os.getenv("DB_PASSWORD"),
)

cur = conn.cursor()
cur.execute("SELECT * FROM pipeline_runs;")

rows = cur.fetchall()
for row in rows:
    print(row)

cur.close()
conn.close()
```

---

# 🔗 Where these values come from

From your `docker-compose.yml`:

```yaml
environment:
  - DB_HOST=postgres
  - DB_PORT=5432
  - DB_NAME=studybook
  - DB_USER=pipeline
  - DB_PASSWORD=...
```

👉 Docker injects these into the container automatically.

# 🧠 The important line

```python
host="postgres"
```

👉 This is NOT a normal hostname.

It works because:

> Docker created a network where `postgres` = the database container
