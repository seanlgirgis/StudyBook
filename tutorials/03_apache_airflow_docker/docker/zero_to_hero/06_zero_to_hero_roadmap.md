# 06 - Zero to Hero Roadmap

## Level 0 (Today)

- Bring stack up
- Run smoke test
- Trigger one sample DAG

## Level 1 (This Week)

- Write 2 DAGs (daily + manual)
- Add retries and logging
- Use Airflow Variables for config

## Level 2

- Add sensors and branching
- Add data quality checks
- Add alert callback on failure

## Level 3

- Add custom image with dependencies
- Add CI check for DAG import
- Add secrets backend pattern

If you complete Level 0-2, you already have practical Airflow skills for many junior-to-mid DE tasks.
