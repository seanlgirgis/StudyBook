# 06 - Docker vs Local Spark

Back to [Docker Pack Index](./README.md)

## Docker Spark advantages

- Reproducible environment for all collaborators
- Fewer host-OS dependency issues
- Easier onboarding and reset
- Cleaner path to cloud deployment

## Local machine Spark advantages

- Fewer moving parts for tiny tests
- Can be fast for one-person exploration

## Practical tradeoff summary

- For educational team tutorials: Docker wins.
- For throwaway solo tests: local can be okay.

## In this project

Given earlier Windows-local instability, Docker is the stable default for this lane.
