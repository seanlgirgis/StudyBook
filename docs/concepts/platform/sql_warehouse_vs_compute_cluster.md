# SQL Warehouse vs Compute Cluster

## Definition
A SQL Warehouse is optimized for SQL analytics. A Compute Cluster is general Spark compute for ETL/ML workloads.

## Why It Matters
Choosing the right compute target affects cost, performance, and operational complexity.
