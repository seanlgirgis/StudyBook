# Code Assessment Practice Set

Date created: 2026-04-05
Purpose: practice core coding interview patterns before the 70-minute CodeSignal assessment.

## How to Use This

- Solve each problem in Python.
- First pass target: correctness.
- Second pass target: cleaner code and edge-case coverage.
- Mark each item `Done` only when you can solve it without help.

## Practice Questions

1. [ ] Two Sum
- Given array `nums` and integer `target`, return indices of two numbers such that they add up to `target`.

2. [ ] Valid Parentheses
- Given string containing only `()[]{}`, determine if input string is valid.

3. [ ] Longest Substring Without Repeating Characters
- Return the length of the longest substring without duplicate characters.

4. [ ] Product of Array Except Self
- Return array where each element is product of all other elements. No division.

5. [ ] Merge Intervals
- Given list of intervals, merge all overlapping intervals.

6. [ ] Top K Frequent Elements
- Return the `k` most frequent elements in an array.

7. [ ] Group Anagrams
- Group words that are anagrams into lists.

8. [ ] Search in Rotated Sorted Array
- Find target index in rotated sorted array, or `-1` if absent.

9. [ ] Min Stack
- Design stack supporting `push`, `pop`, `top`, and `getMin` in O(1).

10. [ ] Daily Temperatures
- For each day, return number of days until a warmer temperature.

11. [ ] Number of Islands
- Count connected components of `1`s in a 2D grid.

12. [ ] Clone Graph
- Return a deep copy of an undirected graph.

13. [ ] Course Schedule
- Given course prerequisites, determine if all courses can be finished.

14. [ ] Kth Largest Element in an Array
- Return the kth largest element (not kth distinct).

15. [ ] Find Median from Data Stream
- Support `addNum` and `findMedian` efficiently over a stream of integers.

16. [ ] Longest Increasing Subsequence
- Return length of the longest strictly increasing subsequence.

17. [ ] Coin Change
- Return minimum number of coins to make amount, or `-1` if impossible.

18. [ ] House Robber
- Return max amount you can rob without robbing adjacent houses.

19. [ ] Decode Ways
- Count number of ways to decode a numeric string where `1-26` map to letters.

20. [ ] LRU Cache
- Implement LRU cache with O(1) `get` and `put`.
