- B) AI Economy / Independent Contractor Path
- C) Income Now

## How to use this repo daily
- Review `income_now/next_actions.md` first and choose today's cash-flow tasks.
- Review `jobsearch_v2/next_actions.md` and complete 1-2 low-friction applications/outreach actions.
- Review `ai_income/next_actions.md` and ship one small demo or client-facing artifact.
- Log key decisions in `DECISION_LOG.md`.
- End day with quick notes for tomorrow in `WEEKLY_EXECUTION.md`.
