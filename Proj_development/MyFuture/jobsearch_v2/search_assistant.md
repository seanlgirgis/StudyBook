# 🔎 JobSearch 2.0 — Search Assistant (One Page)

## 🎯 Objective
Find and apply to **high-probability jobs quickly**.  
Not perfect jobs. Not dream jobs. **Jobs that can say YES fast.**

---

## ⚡ Daily Rule

Every session must produce:

- [ ] 3 jobs reviewed
- [ ] 2–3 applications submitted
- [ ] 1–2 outreach messages (optional)

---

## 🔍 Where to Search

Primary:
- LinkedIn
- Indeed
- Dice

Secondary:
- Upwork (AI / data gigs)
- Staffing agencies (TEKsystems, Robert Half, Insight Global)

---

## 🔑 Search Terms (Rotate)

### 🅰️ Data Engineer
- "Data Engineer AWS"
- "PySpark Data Engineer"
- "ETL Data Engineer contract"
- "Data Engineer remote"

### 🅱️ Performance / Capacity
- "Capacity Planning Engineer"
- "Performance Engineer monitoring"
- "APM Engineer Dynatrace AppDynamics"
- "Observability Engineer"

### 🅲 Hybrid / Easier Entry
- "Data Platform Engineer"
- "Analytics Engineer"
- "Cloud Data Engineer"

### 🅳 Always Try Adding
- "contract"
- "immediate hire"
- "6 month"

---

## ⚖️ Friction Scoring (2–3 min MAX)

Score quickly (0–2 each):

- Hiring speed (urgent?)
- Process (simple?)
- Stack match?
- Overqualification risk?
- Role clarity?
- Compensation fit?

### Decision

- **9–12 → APPLY**
- **6–8 → Maybe (quick judgment)**
- **0–5 → SKIP**

---

## ❌ Hard Skip (No Thinking)

- Proctored coding tests
- 5+ interview rounds
- FAANG-style process
- Clearly junior roles

---

## 🎯 Choose Resume Angle (IMPORTANT)

Pick ONE:

- Data Engineer → pipelines, AWS, Spark
- Performance → monitoring, capacity, APM
- AI/Data → RAG, automation, AI workflows

👉 Do NOT mix angles

---

## ⚙️ Apply Pipeline (Your System)

Run:

```

job-check.ps1
job-score.ps1
job-accept.ps1
job-run.ps1

```

Then:

```

job-apply.ps1

```

---

## ⏱️ Time Rules

- 2–3 min per job (max)
- No deep reading before scoring
- No perfection edits on resume

---

## 🧠 Mindset Rules

- Speed > perfection
- Volume > overthinking
- Repetition builds results
- You are filtering THEM, not begging

---

## 🚫 Common Traps

- Reading job description too long
- Trying to match 100%
- Over-editing resume
- Applying to low-probability jobs

---

## 🔁 Loop

1. Search
2. Score
3. Decide
4. Apply
5. Repeat

---

## 💬 If Stuck

Ask:
- “Is this job worth applying?”
- “Which angle?”
- “Tighten this resume”

---

## 🔥 Reminder

You don’t need the perfect job.

You need:
👉 **the next paycheck**
👉 **the next opportunity**
👉 **momentum**

---

## ✅ Session Complete When

- [ ] 2–3 applications sent
- [ ] No overthinking
- [ ] You stayed within time rules
