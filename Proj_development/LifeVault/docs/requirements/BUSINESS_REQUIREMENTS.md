# BUSINESS_REQUIREMENTS.md

- LifeVault must provide a trustworthy personal memory map across mixed data sources.
- Human approval is mandatory before risky state changes (publish, cleanup, sensitive actions).
- The clean vault remains the final trusted file source.
- The operational database remains the searchable governance map.
- Early workflows prioritize proposal and review over automation depth.
- The system must support one-writer/many-reader operations.
