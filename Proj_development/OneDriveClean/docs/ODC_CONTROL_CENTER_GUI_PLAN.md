# ODC Control Center GUI Plan

Status: Initial implementation now exists at `app/odc_control_center.py`.

- source folder input
- story/context input
- proposal generation
- editable pod fields
- create pod button
- index pod button
- duplicate detection button
- result/status display

- richer proposal explainability
- pending pod list
- database search panel
- future vault publish workflow (approval-gated)

Safety gates remain mandatory.
