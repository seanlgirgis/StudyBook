# Nuggets

This repository is my IT learning scratchbook.

It is used for small experiments, practice examples, interview prep code, testing ideas, AWS simulations, data engineering patterns, Python practice, and quick proofs of concept.

## Start Environment

From this folder:

```powershell
..\env_setter.ps1
```

Then run Python examples using relative paths.

Example:

```powershell
python .\python\001_environment_check\demo.py
```

## Main Rule

Each nugget should be small, focused, runnable, and easy to delete or improve later.

## Suggested Areas

- `python/` - Python basics, utilities, file handling, typing, packaging
- `data_engineering/` - ETL, CSV, Parquet, Spark ideas, pipelines
- `aws/` - local AWS concepts, boto3 patterns, mock examples
- `testing/` - pytest, mocks, fixtures, integration testing
- `architecture/` - design sketches, tradeoffs, system thinking
- `scratch/` - temporary experiments
- `templates/` - reusable starter templates
