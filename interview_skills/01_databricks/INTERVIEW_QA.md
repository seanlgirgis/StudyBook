# Databricks Interview Q&A

## 1) What is Databricks?
A managed Spark platform used to build and run data pipelines and analytics workflows with Python and SQL.

## 2) How much Databricks experience do you have?
I position it as practical exposure and study built on strong Spark and AWS data engineering foundations.

## 3) Have you used Databricks in production?
My strongest production experience is broader Python/AWS/PySpark engineering. Databricks depth is developing and practical.

## 4) Why Delta tables?
They improve reliability with ACID behavior, schema controls, and versioned table operations.

## 5) What are Jobs/Workflows used for?
Scheduling and orchestrating repeatable pipeline tasks with retries and task dependencies.

## 6) How do you use SQL in Databricks?
For validation queries, data modeling steps, and business-facing curated tables.

## 7) Explain Structured Streaming simply.
Spark processes incoming records as an unbounded table in micro-batches with checkpoints for fault tolerance.

## 8) What is Unity Catalog?
A governance layer for centralized permissions, metadata organization, and lineage.

## 9) What is DLT?
A managed pipeline framework where you define table transformations and quality expectations declaratively.

## 10) How do you approach deduplication and entity resolution?
Normalize fields, create match keys, use similarity scoring, apply threshold bands, and track decisions for auditing.
