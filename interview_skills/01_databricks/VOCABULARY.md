# Databricks Vocabulary

- Workspace: Shared Databricks environment for assets and permissions.
- Notebook: Interactive code and documentation file.
- Compute: Runtime resources for execution.
- Cluster: Configurable Spark compute target.
- Serverless: Managed compute option.
- DataFrame: Distributed tabular abstraction in Spark.
- Delta Lake: Transaction layer on lake storage.
- Delta table: Table stored in Delta format.
- Merge: Upsert-style operation for matched keys.
- Checkpoint: Stored streaming progress/state metadata.
- Unbounded table: Streaming conceptual table that continuously grows.
- Trigger interval: How often micro-batches run.
- Sink: Streaming output destination.
- Unity Catalog: Governance and metadata layer.
- DLT: Managed declarative data pipeline framework.
- Bronze/Silver/Gold: Raw, refined, and business-ready data layers.
- Lineage: Data flow visibility from source to output.
- Schema evolution: Controlled handling of structural data changes.
