# Python Mastery Frozen Notebook Naming Convention

Use this format for reusable review notebooks:

`python_mastery_NN_topic.ipynb`

- `NN`: two-digit sequence (`01`, `02`, ...)
- `topic`: lowercase snake_case topic slug
- Keep one topic per notebook
- Treat these as frozen review assets (append via new numbered notebook, avoid overwriting old learning history)

Examples:
- `python_mastery_01_hashmaps_sets.ipynb`
- `python_mastery_02_grids_boundaries.ipynb`
- `python_mastery_03_sorting_keys.ipynb`
