Prompt construction

PromptTemplate.from_template() creates one reusable text recipe. ChatPromptTemplate.from_messages() creates role-based messages.

The three invoke calls

prompt.invoke() prepares. model.invoke() generates. chain.invoke() runs everything.

Few-shot prompting

Prefix + formatted examples + suffix. input_variables declares the runtime fields supplied later.

LCEL

chain = prompt | model | parser. Construct once, invoke repeatedly.

RunnableParallel

Independent branches receive the same original input. Branch names become result dictionary keys.

Structured output

JsonOutputParser returned a dictionary. with_structured_output() returned a validated Pydantic object.

Conversation history

MessagesPlaceholder("history") inserts earlier messages. Manual lists disappear when the process ends.

Provider switching

The same prompt, parser, input, and chain shape ran with ChatOpenAI and ChatWatsonx.

Core code patterns

Text prompt

prompt = PromptTemplate.from_template(
    "Explain {topic}."
)

formatted = prompt.invoke(
    {"topic": "RAG"}
)

Chat prompt

prompt = ChatPromptTemplate.from_messages(
    [
        ("system", "You are a tutor."),
        ("human", "{question}"),
    ]
)

LCEL

chain = prompt | model | StrOutputParser()
result = chain.invoke({"topic": "LCEL"})

Provider-native structured output

structured_model = model.with_structured_output(TopicSummary)
chain = prompt | structured_model
result = chain.invoke({"topic": "prompt templates"})
print(result.topic)

Memory checks

Sequence: later steps depend on earlier outputs. Parallel: independent branches share the same input.
Self-consistency: ask several times, compare candidate answers, and choose the strongest agreement. More reliable can also mean more expensive and slower.
