## Completion standard

A topic is complete only when:

- the concept can be explained plainly;
- the small code skeleton can be reconstructed;
- the local example runs;
- the corresponding Coursera exercise or lab runs;
- important confusion is captured in RemNote;
- documentation contains the final proven pattern.
