# RAG Application Builder Foundation

This is the local preparation and understanding layer for the IBM Coursera
specialization **RAG for Generative AI Applications**.

It is not a fifth Coursera course.

## Purpose

```text
Completed DataCamp AI learning
        +
tiny transparent application-building labs
        +
IBM watsonx.ai comparison work
        +
actual Coursera curriculum reconnaissance
        =
strong preparation for the four official IBM courses
```

## Primary learning rule

Build every important component visibly before hiding it behind a framework.

```text
plain-English idea
→ tiny script
→ run it
→ inspect the output
→ explain each component
→ add one Lego block
```

## Provider strategy

- OpenAI is the primary local provider.
- IBM watsonx.ai is incorporated where it adds learning value or mirrors
  Coursera material.
- Coursera-required IBM or Hugging Face work remains valid official evidence.
- Do not duplicate every lab for every provider.

## Start here

1. Open `ROADMAP.md`.
2. Open `docs/DATACAMP_REUSE_MAP.md`.
3. Begin with `lab/python/stage_01_application_basics/`.
4. Record every run in `lab/lab_run_book.md`.
5. Add Coursera reconnaissance findings to
   `source_material/coursera/COURSE_RECONNAISSANCE.md`.
