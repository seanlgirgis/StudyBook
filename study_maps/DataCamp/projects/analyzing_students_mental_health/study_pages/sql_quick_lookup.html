SQL Quick Lookup

The smallest useful syntax for filtering, cleaning, grouping, averaging, rounding, sorting, validating, and explaining this project.

Filter Nulls Group Count Average Round Sort CTE Having Validation Final Query

Filter rows with WHERE

WHERE

Use WHERE to keep only international students.

WHERE inter_dom = 'Inter'
Trap: forgetting this filter mixes domestic and international students.

Remove incomplete rows

IS NOT NULL

Keep only rows with values in every field used by the analysis.

WHERE inter_dom IS NOT NULL
  AND stay IS NOT NULL
  AND todep IS NOT NULL
  AND tosc IS NOT NULL
  AND toas IS NOT NULL
Trap: use IS NULL or IS NOT NULL, not = NULL.

Create stay groups

GROUP BY

Create one result row for each length-of-stay value.

GROUP BY stay
Trap: every selected column that is not aggregated must normally appear in GROUP BY.

Count students per group

COUNT

Count all rows inside each stay group.

COUNT(*) AS count_int
Trap: COUNT(column) ignores null values in that column.

Calculate group averages

AVG 
AVG(todep)  -- depression
AVG(tosc)   -- social connectedness
AVG(toas)   -- acculturative stress
Trap: averages can look precise even when the group contains only one student. Always read the count with the average.

Round to two decimals

ROUND

Wrap the aggregate inside ROUND().

ROUND(AVG(todep), 2) AS average_phq
PostgreSQL supports rounding a numeric value to the requested number of decimal places.

Sort longest stay first

ORDER BY 
ORDER BY stay DESC
DESC means high to low. ASC means low to high.

Separate cleaning with a CTE

WITH 
WITH clean_students AS (
    SELECT
        inter_dom,
        stay,
        todep,
        tosc,
        toas
    FROM students
    WHERE stay IS NOT NULL
)
SELECT *
FROM clean_students;
A CTE improves readability here, but it is not required for such a small query.

Filter groups with HAVING

HAVING

Use HAVING after grouping to keep only larger groups.

GROUP BY stay
HAVING COUNT(*) >= 5
WHERE filters rows before grouping. HAVING filters groups after grouping.

Name result columns

AS 
COUNT(*) AS count_int
ROUND(AVG(todep), 2) AS average_phq
Match the exact aliases required by the project instructions.

Validation checks

VERIFY
Question SQL Expected
How many source rows loaded? SELECT COUNT(*) FROM students; 286
How many complete international rows are analyzed? SELECT COUNT(*) ... WHERE inter_dom = 'Inter' ... 201
How many stay groups? SELECT COUNT(DISTINCT stay) ... 9
How large is the final result? Run the final grouped query. 9 rows × 5 columns

Final project query

SOLUTION 
WITH clean_students AS (
    SELECT
        inter_dom,
        stay,
        todep,
        tosc,
        toas
    FROM students
    WHERE inter_dom IS NOT NULL
      AND stay IS NOT NULL
      AND todep IS NOT NULL
      AND tosc IS NOT NULL
      AND toas IS NOT NULL
)
SELECT
    stay,
    COUNT(*) AS count_int,
    ROUND(AVG(todep), 2) AS average_phq,
    ROUND(AVG(tosc), 2) AS average_scs,
    ROUND(AVG(toas), 2) AS average_as
FROM clean_students
WHERE inter_dom = 'Inter'
GROUP BY stay
ORDER BY stay DESC;

Useful mental model

ORDER

Think through the query in this practical order:

FROM
→ WHERE
→ GROUP BY
→ HAVING
→ SELECT
→ ORDER BY
This is a reasoning model, not the written clause order of every SQL statement.
