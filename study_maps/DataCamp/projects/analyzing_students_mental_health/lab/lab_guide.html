Create the table

Open psql and connect to the local database:

psql -U postgres -d observability

Move to the SQL folder from inside psql:

\cd D:/Workarea/StudyBook/study_maps/DataCamp/projects/analyzing_students_mental_health/lab/sql

Create the table:

\i 00_create_students_table.sql
Expected messages include DROP TABLE, CREATE TABLE, and several COMMENT confirmations.

Inspect the table definition:

\d students
3

Load the CSV

Run the loader:

\i 01_load_students_csv.sql
The file uses \copy, so the CSV is read by the local psql client. This is usually easier than server-side COPY on Windows.

Expected validation:

loaded_rows
-----------
286
The loader truncates the table first. Re-running it replaces the current rows instead of creating duplicates.
4

Run the project solution

\i 02_project_solution.sql

The query performs these steps:

Clean Remove incomplete rows for the fields used by the analysis.
Filter Keep only inter_dom = 'Inter'.
Group Create one group for each stay value.
Summarize Count students and average the three score columns.

Practice beyond the project

Run the practice file:

\i 03_practice_queries.sql

It includes:

  • table inspection and row counts
  • international versus domestic comparisons
  • missing-value checks with FILTER
  • grouped averages by stay, gender, and age
  • a CTE plus CROSS JOIN comparison
  • ranking with DENSE_RANK()
  • an unfinished exercise using HAVING
Best next exercise: return only stay groups with at least five international students, then sort by average depression score from highest to lowest.

Troubleshooting

\i says “No such file or directory”

Either change the psql working directory with \cd, or provide the full path: 

\i D:/Workarea/StudyBook/study_maps/DataCamp/projects/analyzing_students_mental_health/lab/sql/02_project_solution.sql

The CSV cannot be found

Confirm this file exists:

D:\Workarea\StudyBook\study_maps\DataCamp\projects\analyzing_students_mental_health\source_material\students.csv

The load creates duplicates

Use the provided loader, which runs TRUNCATE TABLE students; before loading.

The row count is not 286

Check that the correct CSV was used and that the table was not partially loaded. Re-run the create and load scripts in order.

See the troubleshooting notes for the project-specific issue log.
