2. Core Mental Model

Window functions calculate across related rows while preserving each detail row.
GROUP BY        → fewer rows
Window function → same rows + analytical column
function_expression OVER (
  PARTITION BY grouping_column
  ORDER BY ordering_column
  ROWS BETWEEN frame_start AND frame_end
)

3. Window Foundations

OVER()

Marks the function as a window calculation.

ORDER BY

Controls the sequence used by the calculation.

PARTITION BY

Restarts the calculation for each group.

ROW_NUMBER()

Assigns a unique sequence number to every row.

ROW_NUMBER() OVER (
  PARTITION BY gender, event
  ORDER BY year
)

4. Fetching, Ranking, and Paging

FunctionRule
LAGPrevious row
LEADFollowing row
FIRST_VALUEFirst value in frame
LAST_VALUELast value in frame; often needs UNBOUNDED FOLLOWING
ROW_NUMBER → unique
RANK       → ties with gaps
DENSE_RANK → ties without gaps
NTILE(3) OVER (ORDER BY medals DESC)
NTILE balances row counts, not value ranges.

5. Aggregate Windows and Frames

SUM(medals) OVER (
  PARTITION BY country
  ORDER BY year
  ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
)
AVG(medals) OVER (
  PARTITION BY country
  ORDER BY year
  ROWS BETWEEN 2 PRECEDING AND CURRENT ROW
)
FrameMeaning
ROWSPhysical records
RANGELogical peers based on ORDER BY values

6. Beyond Window Functions

CROSSTAB

Pivot row categories into columns. Requires tablefunc and an explicit output schema.

ROLLUP

Hierarchical subtotals.

CUBE

All subtotal combinations.

COALESCE

Replace structural nulls with readable labels.

STRING_AGG

Concatenate ordered values into one text summary.

Aggregate first
→ rank second
→ pivot or summarize third

7. Common Mistakes

  • Confusing window ORDER BY with final query ORDER BY.
  • Forgetting PARTITION BY and allowing calculations to cross groups.
  • Using LAST_VALUE without extending the frame.
  • Choosing the wrong ranking function for ties.
  • Miscounting frame rows.
  • Using RANGE when exact physical rows are required.
  • Confusing ROLLUP with CUBE.

8. Interview Review

What is a window function?
A calculation across rows related to the current row that preserves every detail row.

RANK versus DENSE_RANK?
Both preserve ties; RANK leaves gaps and DENSE_RANK does not.

What is a frame?
The subset of ordered rows used for the current row’s calculation.

ROWS versus RANGE?
ROWS counts records; RANGE groups rows sharing the same ordering value.

ROLLUP versus CUBE?
ROLLUP follows a hierarchy; CUBE returns every subtotal combination.

Interview sentence: I use window functions for ranking, row-to-row comparisons, running totals, moving statistics, and grouped analytical calculations without collapsing detailed rows.
