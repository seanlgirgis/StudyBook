Foundations

OVER()

Turn a supported function into a window calculation.

function_expression OVER ()
OVER does not itself define ordering or partitioning.

ORDER BY inside OVER

Define the sequence used by the calculation.

ROW_NUMBER() OVER (ORDER BY year)
This is separate from the final query ORDER BY.

PARTITION BY

Restart the calculation per group.

ROW_NUMBER() OVER (PARTITION BY event ORDER BY year)
Omitting it may mix unrelated groups.

Fetching and Ranking

LAG

Fetch a prior row value.

LAG(value, 1) OVER (PARTITION BY group_col ORDER BY time_col)
The offset counts rows, not time units.

LEAD

Fetch a following row value.

LEAD(value, 1) OVER (PARTITION BY group_col ORDER BY time_col)
The last rows may return NULL.

FIRST_VALUE

Return the first value in the frame.

FIRST_VALUE(value) OVER (ORDER BY sort_col)
Frame boundaries still matter.

LAST_VALUE

Return the final value in the frame.

LAST_VALUE(value) OVER (ORDER BY sort_col RANGE BETWEEN UNBOUNDED PRECEDING AND UNBOUNDED FOLLOWING)
Without UNBOUNDED FOLLOWING, it may return the current value.

ROW_NUMBER

Assign a unique sequence.

ROW_NUMBER() OVER (ORDER BY value DESC)
Ties still receive different numbers.

RANK

Competition ranking with gaps.

RANK() OVER (ORDER BY value DESC)
Ties cause gaps.

DENSE_RANK

Tie-aware ranking without gaps.

DENSE_RANK() OVER (ORDER BY value DESC)
Do not use when gaps are meaningful.

NTILE

Split ordered rows into buckets.

NTILE(3) OVER (ORDER BY value DESC)
Balances row counts, not value ranges.

Aggregates and Frames

Running total

Cumulative total through the current row.

SUM(value) OVER (PARTITION BY group_col ORDER BY time_col ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW)
Include PARTITION BY when totals must restart.

Moving average

Average a bounded recent window.

AVG(value) OVER (ORDER BY time_col ROWS BETWEEN 2 PRECEDING AND CURRENT ROW)
2 preceding plus current equals up to 3 rows.

Moving total

Sum a bounded recent window.

SUM(value) OVER (ORDER BY time_col ROWS BETWEEN 2 PRECEDING AND CURRENT ROW)
Early rows use fewer observations.

Centered frame

Use rows before and after the current row.

MAX(value) OVER (ORDER BY time_col ROWS BETWEEN 1 PRECEDING AND 1 FOLLOWING)
Boundary rows have smaller frames.

ROWS

Count physical rows.

ROWS BETWEEN 3 PRECEDING AND CURRENT ROW
This can include up to 4 rows.

RANGE

Include peers sharing ORDER BY values.

RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
Duplicates can expand the frame.

Beyond Window Functions

CROSSTAB

Pivot row values into columns.

SELECT * FROM CROSSTAB($$ source_query $$) AS ct (row_key text, "2008" integer, "2012" integer);
Requires tablefunc and an explicit output schema.

ROLLUP

Create hierarchical subtotals.

GROUP BY ROLLUP(year, quarter)
Column order defines the hierarchy.

CUBE

Create all subtotal combinations.

GROUP BY CUBE(country, medal)
Produces more grouping sets than ROLLUP.

COALESCE

Replace NULL with the first non-null value.

COALESCE(country, 'All countries')
Subtotal NULLs may be structural, not missing data.

STRING_AGG

Combine rows into an ordered string.

STRING_AGG(country, ', ' ORDER BY rank_n)
Put ORDER BY inside STRING_AGG when sequence matters.
