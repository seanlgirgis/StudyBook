2. Pivoting

Pivoting converts distinct row values into columns. A common example is turning Olympic years into separate columns so each country appears once.

Before Country | Year | Awards CHN | 2008 | 74 CHN | 2012 | 56 RUS | 2008 | 62 RUS | 2012 | 47 After Country | 2008 | 2012 CHN | 74 | 56 RUS | 62 | 47
Use case: Pivoting is useful when reporting tools or readers need categories displayed horizontally rather than vertically.

3. PostgreSQL CROSSTAB()

CROSSTAB() is provided by PostgreSQL’s tablefunc extension.

CREATE EXTENSION IF NOT EXISTS tablefunc;

Basic source query

SELECT
    Country,
    Year,
    COUNT(*) AS Awards
FROM Summer_Medals
WHERE Country IN ('CHN', 'RUS', 'USA')
  AND Year IN (2008, 2012)
  AND Medal = 'Gold'
GROUP BY Country, Year
ORDER BY Country, Year;

Pivot query

SELECT *
FROM CROSSTAB(
  $$
    SELECT
      Country,
      Year,
      COUNT(*) AS Awards
    FROM Summer_Medals
    WHERE Country IN ('CHN', 'RUS', 'USA')
      AND Year IN (2008, 2012)
      AND Medal = 'Gold'
    GROUP BY Country, Year
    ORDER BY Country, Year
  $$
) AS ct (
  Country varchar,
  "2008" integer,
  "2012" integer
)
ORDER BY Country;
Critical rule: PostgreSQL must know the pivoted output columns and data types in advance. The column definition after AS ct (...) is mandatory.

4. Pivoting with Ranking

Window functions can prepare values before pivoting. For example, rank countries by medal count within each year, then pivot the ranks into separate year columns. 

WITH Country_Awards AS (
  SELECT
    Country,
    Year,
    COUNT(*) AS Awards
  FROM Summer_Medals
  WHERE Country IN ('CHN', 'RUS', 'USA')
    AND Year IN (2008, 2012)
    AND Medal = 'Gold'
  GROUP BY Country, Year
),
Country_Ranks AS (
  SELECT
    Country,
    Year,
    RANK() OVER (
      PARTITION BY Year
      ORDER BY Awards DESC
    )::integer AS Rank
  FROM Country_Awards
)
SELECT *
FROM CROSSTAB(
  $$
    SELECT Country, Year, Rank
    FROM Country_Ranks
    ORDER BY Country, Year
  $$
) AS ct (
  Country varchar,
  "2008" integer,
  "2012" integer
);
Pattern: Aggregate first, rank second, pivot third.

5. ROLLUP

ROLLUP adds hierarchical subtotal rows following the order of the grouped columns. 

SELECT
  Country,
  Medal,
  COUNT(*) AS Awards
FROM Summer_Medals
WHERE Year = 2008
  AND Country IN ('CHN', 'RUS')
GROUP BY Country, ROLLUP(Medal)
ORDER BY Country, Medal;

This returns:

  • Country + Medal detail totals
  • Country-level subtotal rows where Medal is NULL

Hierarchical example

SELECT
  Year,
  Quarter,
  SUM(Sales) AS Sales
FROM Quarterly_Sales
GROUP BY ROLLUP(Year, Quarter)
ORDER BY Year, Quarter;
Decision rule: Use ROLLUP when the grouping columns form a natural hierarchy such as year → quarter.

6. CUBE

CUBE returns every possible subtotal combination for the listed grouping columns, plus the grand total. 

SELECT
  Country,
  Medal,
  COUNT(*) AS Awards
FROM Summer_Medals
WHERE Year = 2008
  AND Country IN ('CHN', 'RUS')
GROUP BY CUBE(Country, Medal)
ORDER BY Country, Medal;
Grouping setIncluded by ROLLUP?Included by CUBE?
Country + MedalYesYes

Difference: ROLLUP follows a hierarchy. CUBE returns all subtotal combinations.

7. Cleaning Up Results with COALESCE()

Subtotal and grand-total rows often contain NULL grouping values. COALESCE() returns the first non-null expression and can replace those nulls with readable labels. 

SELECT
  COALESCE(Country, 'All countries') AS Country,
  COALESCE(Medal, 'All medals') AS Medal,
  COUNT(*) AS Awards
FROM Summer_Medals
WHERE Year = 2008
  AND Country IN ('CHN', 'RUS')
GROUP BY ROLLUP(Country, Medal)
ORDER BY Country, Medal;
COALESCE(value_1, value_2, value_3)

The function searches from left to right and returns the first non-null value.

Other uses: COALESCE() can also replace nulls returned by LAG(), LEAD(), and pivoted columns.

8. Summarizing Results with STRING_AGG()

STRING_AGG() concatenates values from multiple rows into one delimited string. 

WITH Country_Medals AS (
  SELECT
    Country,
    COUNT(*) AS Medals
  FROM Summer_Medals
  WHERE Year = 2012
    AND Country IN ('CHN', 'RUS', 'USA')
    AND Medal = 'Gold'
  GROUP BY Country
),
Country_Ranks AS (
  SELECT
    Country,
    RANK() OVER (
      ORDER BY Medals DESC
    ) AS Rank
  FROM Country_Medals
)
SELECT
  STRING_AGG(Country, ', ' ORDER BY Rank) AS Ranked_Countries
FROM Country_Ranks;

Example result:

CHN, RUS, USA
Why useful: The ranking column may be unnecessary in the final output because the order is encoded in the concatenated list.

9. Common Mistakes

Forgetting to enable tablefunc CROSSTAB() is unavailable until the tablefunc extension is enabled.
Omitting the CROSSTAB output definition PostgreSQL requires the output column names and data types after the function call.
Using an unstable source-query order The pivot source must be ordered consistently by row identifier and category.
Confusing ROLLUP with CUBE ROLLUP gives hierarchical subtotals; CUBE gives all combinations.
Treating subtotal nulls as missing data In grouped subtotal output, nulls may identify the aggregation level rather than bad source data.
Forgetting STRING_AGG ordering Add ORDER BY inside STRING_AGG() when the sequence matters.

10. Interview Translation

What is pivoting? Pivoting transforms category values stored in rows into separate output columns.
What does PostgreSQL CROSSTAB require? It requires the tablefunc extension, an ordered source query, and an explicit output-column definition.
How do ROLLUP and CUBE differ? ROLLUP follows a hierarchy of grouping columns, while CUBE generates every possible subtotal combination.
Why use COALESCE with subtotal queries? It converts structural nulls in subtotal and grand-total rows into meaningful labels.
What does STRING_AGG do? It combines values from multiple rows into one ordered, delimited string.
