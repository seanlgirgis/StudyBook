Chapter Guides

Chapter 1: Processing, Storing, and Organizing Data

Separate operational OLTP work from analytical OLAP work; choose storage, pipelines, and dimensional models from business needs.

Chapter 2: Database Schemas and Normalization

Use star and snowflake schemas intentionally, normalize transactional data, and recognize dependency-driven anomalies.

Chapter 3: Database Views

Use regular and materialized views as managed interfaces, security boundaries, and performance tools.

Chapter 4: Database Management

Control access with roles, scale tables through partitioning, integrate data safely, and select a DBMS by workload.
