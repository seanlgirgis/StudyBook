# Functions for Manipulating Data in PostgreSQL — Lab

This course-local lab practices the four course chapters against a small `dc_functions` schema.

## Run order

1. `sql/00_create_schema.sql`
2. `sql/01_create_tables.sql`
3. `sql/02_insert_sample_data.sql`
4. `sql/03_data_types_and_arrays.sql`
5. `sql/04_date_time_functions.sql`
6. `sql/05_text_functions.sql`
7. `sql/06_full_text_search_and_extensions.sql`

The extension portion is optional because database privileges vary.
