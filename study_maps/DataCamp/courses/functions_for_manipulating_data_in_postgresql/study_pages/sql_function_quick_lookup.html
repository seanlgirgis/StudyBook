Types, Arrays, and Metadata

Inspect column metadata

Confirm the stored and underlying PostgreSQL types before choosing functions.

SELECT column_name, data_type, udt_name
FROM information_schema.columns
WHERE table_name = 'film';
Column names do not prove data types; arrays and user-defined types often require udt_name.

Match an array element with ANY

Return rows where a scalar matches at least one array element.

SELECT title
FROM film
WHERE 'Trailers' = ANY (special_features);
Put the scalar on the left and the array expression inside ANY().

Test array containment

Return rows whose array contains all elements in another array.

SELECT title
FROM film
WHERE special_features @> ARRAY['Trailers']::text[];
Both sides must be compatible array types; an explicit cast can avoid ambiguity.

Date and Time

Date and timestamp subtraction

Calculate day counts or elapsed intervals.

SELECT DATE '2026-06-10' - DATE '2026-06-01';
SELECT TIMESTAMP '2026-06-10 18:00'
     - TIMESTAMP '2026-06-09 08:30';
Date subtraction and timestamp subtraction return different kinds of values.

Add an interval

Move a date or timestamp by a defined duration.

SELECT rental_date
     + rental_duration * INTERVAL '1 day'
       AS expected_return_date
FROM rental_schedule;
Do not add a raw integer to a timestamp when the intended unit should be explicit.

Extract versus truncate

Get one component or align a timestamp to a reporting boundary.

SELECT EXTRACT(YEAR FROM rental_date),
       DATE_TRUNC('month', rental_date)
FROM rental;
EXTRACT returns a component; DATE_TRUNC returns a timestamp.

Text Formatting and Parsing

Normalize and combine text

Create clean display values from multiple text fields.

SELECT INITCAP(TRIM(first_name || ' ' || last_name))
FROM customer;
The || operator can produce NULL when an operand is NULL; consider CONCAT or COALESCE.

Locate a delimiter

Find the position needed for later extraction.

SELECT POSITION('@' IN email),
       STRPOS(email, '@')
FROM customer;
A zero position means the delimiter was not found; validate before subtracting or slicing.

Extract username and domain

Split an email address around the at-sign.

SELECT SUBSTRING(email FROM 1 FOR POSITION('@' IN email)-1),
       SUBSTRING(email FROM POSITION('@' IN email)+1)
FROM customer;
Malformed or missing delimiters can produce incorrect boundaries.

Search, Types, and Extensions

Pattern matching

Match simple literal prefixes, suffixes, or substrings.

SELECT title
FROM film
WHERE title ILIKE '%elf%';
Leading wildcards can prevent efficient ordinary index use.

Full-text search

Search normalized words using text-search vectors and queries.

SELECT title
FROM film
WHERE to_tsvector('english', title || ' ' || description)
      @@ to_tsquery('english', 'elf');
Use the same language configuration consistently for vector and query generation.

Fuzzy matching extensions

Compare strings by similarity or edit distance.

CREATE EXTENSION IF NOT EXISTS pg_trgm;
CREATE EXTENSION IF NOT EXISTS fuzzystrmatch;
SELECT similarity(title, 'GAMBOL'),
       levenshtein(lower(title), 'gambol')
FROM film;
Extensions may be unavailable or require installation privileges.

Function-selection map

Input type ├─ array → ANY / @> ├─ date/time → subtraction / interval / EXTRACT / DATE_TRUNC ├─ text → normalize / locate / extract / pad └─ documents → LIKE or full-text search Always validate return type, nulls, malformed values, and extension availability.
The reliable sequence is: inspect the input type, choose the desired operation, confirm the return type, then test edge cases.
