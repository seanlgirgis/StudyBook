Chapter Guides

Chapter 1 — Overview of Common Data Types

PostgreSQL data types, type inspection, casting, arrays, ANY, and containment operators.

Chapter 2 — Working with DATE/TIME Functions and Operators

Timestamp arithmetic, intervals, AGE, EXTRACT, DATE_PART, DATE_TRUNC, and current date/time.

Chapter 3 — Parsing and Manipulating Text

String formatting, parsing, truncation, padding, trimming, concatenation, and normalization.

Chapter 4 — Full-text Search and PostgreSQL Extensions

PostgreSQL full-text search and extensions that add specialized database capabilities.
