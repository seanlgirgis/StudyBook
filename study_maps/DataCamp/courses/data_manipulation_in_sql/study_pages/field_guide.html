2. Course Big Picture

The course moves from row-level conditional logic to multi-stage SQL and finally to analytics that preserve detail rows.

CASE ↓ conditional values and aggregates Subqueries ↓ inner results used by outer queries Correlated queries and CTEs ↓ row-dependent logic and named stages Window functions ↓ group context without losing detail rows
Course punchline: choose the technique by the required result shape: a value, a list, a temporary table, a named stage, or a calculation across preserved detail rows.

3. Core Concepts

CASE

Creates categories, flags, and conditional values.

Scalar subquery

Returns exactly one value for comparison or display.

Derived table

A subquery in FROM that behaves like a temporary table.

Correlated subquery

References the current outer row.

CTE

A named query step defined with WITH.

Window function

Adds group context while preserving row-level detail.

4. Core Syntax and Patterns

Conditional aggregation

SUM(CASE WHEN condition THEN 1 ELSE 0 END) AS matching_count

AVG(CASE WHEN condition THEN 1.0 ELSE 0.0 END) AS matching_fraction

Correlated comparison

SELECT main.*
FROM match AS main
WHERE main.home_goal + main.away_goal > (
    SELECT AVG(sub.home_goal + sub.away_goal)
    FROM match AS sub
    WHERE sub.country_id = main.country_id
      AND sub.season = main.season
);

Window calculation

SUM(value) OVER (
    PARTITION BY group_column
    ORDER BY date, id
    ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW
)

5. Comparisons and Decision Rules

GROUP BY

Collapses rows into one result per group.

PARTITION BY

Defines groups for a window calculation while retaining detail rows.

6. Common Mistakes

COUNT with ELSE 0COUNT() counts zero because it is non-NULL. Omit ELSE or use SUM.
Using = for a list subqueryUse IN when the inner query can return multiple rows.
NOT IN with NULLA NULL in the list can invalidate the comparison. Filter NULLs or use NOT EXISTS.
Wrong league join keyJoin soccer league and match data using their shared country_id.
LEFT JOIN filtered in WHEREA right-side WHERE condition can remove unmatched rows.
Window without deterministic orderUse a tie-breaker such as ORDER BY date, id.

7. Interview Translation

What is conditional aggregation?It places a CASE expression inside an aggregate so one grouped query can calculate metrics for selected rows.
What is a correlated subquery?It references values from the current outer row and is evaluated in that row's context.
Why use a CTE?To name intermediate logic, break a complex query into testable stages, and improve maintainability.
What is a window function?It calculates across related rows while preserving one output row per input row.
