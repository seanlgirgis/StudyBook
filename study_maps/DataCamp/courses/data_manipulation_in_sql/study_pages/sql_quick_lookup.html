CASE and Conditional Aggregation

Basic CASE

Create a derived category or label.

CASE
  WHEN condition THEN result
  ELSE fallback
END
Conditions are checked top to bottom; the first true branch wins.

Conditional count

Count rows that satisfy a condition.

SUM(CASE
      WHEN condition THEN 1
      ELSE 0
    END)
COUNT(CASE ... ELSE 0 END) counts zero because zero is not NULL.

Conditional fraction

Calculate a proportion with 1 and 0.

AVG(CASE
      WHEN condition THEN 1.0
      ELSE 0.0
    END)
Use decimal values when division or percentages are involved.

Subqueries

Scalar subquery

Compare with one calculated value.

WHERE value > (
  SELECT AVG(value)
  FROM source
)
The inner query must return one value.

List subquery

Filter against multiple returned values.

WHERE id IN (
  SELECT id
  FROM source
  WHERE condition
)
Use IN rather than = when multiple rows can be returned.

Safe anti-filter

Exclude matching rows safely.

WHERE NOT EXISTS (
  SELECT 1
  FROM child c
  WHERE c.key = p.key
)
NOT IN can fail unexpectedly when the subquery returns NULL.

FROM subquery

Query an intermediate result as a table.

FROM (
  SELECT key, AVG(value) AS avg_value
  FROM source
  GROUP BY key
) AS summary
A derived table needs an alias.

SELECT subquery

Add one scalar benchmark column.

SELECT
  group_col,
  (SELECT AVG(value) FROM source) AS overall_avg
FROM source
A SELECT subquery must return a single value for each outer row.

Correlated subquery

Compare an outer row with its own group.

WHERE main.value > (
  SELECT AVG(sub.value)
  FROM source sub
  WHERE sub.group_id = main.group_id
)
The outer reference makes the inner query dependent on the current row.

CTEs and Query Organization

CTE

Name an intermediate query step.

WITH prepared AS (
  SELECT ...
)
SELECT *
FROM prepared;
A CTE mainly improves structure; it is not automatically faster.

Multiple CTEs

Build a readable processing pipeline.

WITH base AS (...),
summary AS (...),
benchmark AS (...)
SELECT ...
FROM summary;
Separate CTEs with commas; use WITH only once.

CTE plus UNION ALL

Stack compatible prepared datasets.

WITH home AS (...),
away AS (...),
all_rows AS (
  SELECT * FROM home
  UNION ALL
  SELECT * FROM away
)
SELECT * FROM all_rows;
Use UNION ALL when duplicate removal is not required.

Window Functions

Window aggregate

Add a group metric without collapsing rows.

AVG(value) OVER (
  PARTITION BY group_id
)
PARTITION BY groups calculations; it does not reduce row count.

Running total

Accumulate values in sequence.

SUM(value) OVER (
  PARTITION BY group_id
  ORDER BY date, id
  ROWS BETWEEN UNBOUNDED PRECEDING
           AND CURRENT ROW
)
Use deterministic ordering when dates can tie.

Moving average

Calculate over nearby rows.

AVG(value) OVER (
  PARTITION BY group_id
  ORDER BY date, id
  ROWS BETWEEN 2 PRECEDING
           AND CURRENT ROW
)
Early rows have partial frames with fewer than three rows.

Rank

Rank rows by a measure.

RANK() OVER (
  PARTITION BY season
  ORDER BY metric DESC
)
RANK leaves gaps after ties; DENSE_RANK does not.

Technique Decision Map

Need a conditional label or metric? → CASE Need one calculated filter value? → Scalar subquery Need a generated list? → IN / EXISTS Need an intermediate table? → FROM subquery Need row-dependent group comparison? → Correlated subquery or window Need named processing stages? → CTE Need group context without row loss? → Window function
Begin with the required output grain and the expected shape of the intermediate result. Then choose the syntax.
