# Local Lab

This is the course-local lab area.

- `python/` — runnable Python examples
- `notebooks/` — Coursera and cleaned notebooks
- `data/` — small non-sensitive datasets
- `expected_outputs/` — observed output evidence
- `notes/` — troubleshooting and design notes
- `source_archive/` — original lab packages

Use OpenAI as the primary local LLM provider unless the course lab requires another provider.
