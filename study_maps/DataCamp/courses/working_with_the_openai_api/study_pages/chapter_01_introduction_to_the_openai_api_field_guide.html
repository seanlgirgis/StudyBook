1. Big Picture

An OpenAI API interaction is a structured exchange between your Python program and an OpenAI service. Your program creates an authenticated client, sends a request to a specific endpoint with a model and messages, receives a structured response object, and then extracts the generated text needed by the application.

Python application | | model + messages + authentication v OpenAI client -> API endpoint -> selected model ^ | | | generated response +------ ChatCompletion object -+ | v response.choices[0].message.content

API endpoints and authentication

Endpoints are service access points. Authentication normally uses a secret API key that proves the request is authorized.

Creating a client and request

Instantiate OpenAI, then call client.chat.completions.create() with a model and a messages list.

Reading the response

The API returns a structured object. The generated text is nested inside the first choice, then message, then content.

Models, messages, and cost awareness

The chosen model affects capability and cost. Usage cost depends on the selected model and the amount of input and output.

Section punchline: Build the client, send model plus messages to the endpoint, then walk through the response object until you reach the content string.

2. API endpoints and authentication

An API endpoint is the access point for a particular service. The course uses the Chat Completions endpoint for conversational text generation. Outside the managed DataCamp environment, requests normally require an API key. Keep that key secret and load it from a secure environment variable rather than hard-coding it in source code.

from openai import OpenAI

client = OpenAI(api_key="<OPENAI_API_TOKEN>")
What to notice: Creating the client does not yet generate text. It prepares the authenticated connection used by later requests.

3. Creating a client and request

A Chat Completions request supplies a model and a list of messages. Each message is a dictionary containing a role and content. In this chapter, the user role carries the instruction or question sent to the model.

response = client.chat.completions.create(
    model="gpt-4o-mini",
    max_completion_tokens=100,
    messages=[
        {
            "role": "user",
            "content": "Write a polite reply accepting an AI Engineer job offer."
        }
    ]
)
Common trap: The messages argument must be a list of dictionaries. A missing role, misspelled key, or incorrectly nested dictionary changes the request structure and can cause failure.

4. Reading the response

The response is not only a string. It is a ChatCompletion object containing metadata, one or more choices, and each choice's message. Read it one level at a time instead of guessing at the final path.

Response level Expression What it returns
First generated choice response.choices[0] The first Choice object in the choices list
Generated text response.choices[0].message.content The model response as a Python string

5. Worked Example

This complete example creates a client, asks for one short productivity tip, and prints only the generated text.

from openai import OpenAI

client = OpenAI(api_key="<OPENAI_API_TOKEN>")

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "user", "content": "Quick productivity tip."}
    ]
)

print(response.choices[0].message.content)
Result: The program prints the first response message's content rather than displaying the entire ChatCompletion object.

6. Validation and Troubleshooting

  • Confirm that OpenAI was imported and that client is an OpenAI client.
  • Check that the request calls client.chat.completions.create().
  • Verify that model is a valid model name and messages is a list.
  • When extracting text, follow the exact path response.choices[0].message.content.
Red flag: Never paste a real secret API key into a public notebook, repository, screenshot, or shared file.

7. Common Mistakes

Calling the endpoint before creating the client Instantiate OpenAI(...) first, assign it to client, and then call the endpoint through that client.
Passing one message dictionary instead of a list Wrap the dictionary in square brackets because messages expects a sequence of messages.
Printing the entire response when only text is needed Use response.choices[0].message.content to extract the generated string.

8. Interview Translation

What is an API endpoint? An endpoint is a specific access point for an API service. The client sends a request to the endpoint that provides the required capability.
How do you structure a basic OpenAI chat request? Create an authenticated OpenAI client, call the Chat Completions create method, specify a model, and provide a messages list containing role-and-content dictionaries.
How do you retrieve the generated text? Read the first element of the choices list, access its message, and then access the content: response.choices[0].message.content.

9. Memory Review

Section summary
  1. Client first: create an OpenAI client before sending requests.
  2. Request shape: model plus a list of role/content messages.
  3. Response path: choices → first choice → message → content.
  4. Protect secret keys and remember that model usage can create cost.
