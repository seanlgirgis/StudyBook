1. Big Picture

Chapter 2 moves beyond simple questions. A prompt can transform existing text, summarize long content, generate new content, or classify inputs. The quality and consistency of the result depend on clear instructions, useful constraints, model settings, and examples.

Task | +--> Edit or summarize existing text +--> Generate new text +--> Classify or score text Prompt design +--> Clear instruction +--> Context and input text +--> Desired format +--> Examples when needed Request controls +--> max_completion_tokens +--> temperature Result +--> response.choices[0].message.content

Text transformation and summarization

Put the instruction first, include the source text clearly, and use f-strings or triple-quoted strings for readable multi-line prompts.

Generation controls and cost

Use max_completion_tokens to cap output length and temperature to influence randomness. Token usage affects cost.

Shot prompting

Zero-shot gives no example, one-shot gives one, and few-shot gives several examples to guide formatting and judgment.

Prompt specificity

Include task, context, audience, tone, and output constraints so the model has less room to guess.

Section punchline: Good prompting is not magic wording. It is clear task definition, relevant context, useful constraints, and examples when consistency matters.

2. Text transformation and summarization

For editing, place the instruction before the text to change. For summarization, tell the model what kind of summary you need, then insert the source text. Triple-quoted strings make multi-line prompts readable, and Python f-strings let you insert variables directly into the prompt.

customer_chat = """Customer: My order arrived damaged.
Agent: I am sorry. I can arrange a replacement.
Customer: Please send it to the same address."""

prompt = f"""Summarize the following customer chat in two bullet points:

{customer_chat}"""

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": prompt}]
)

print(response.choices[0].message.content)
What to notice: The model receives one finished string. The f-string is only a convenient Python technique for inserting the source text into that string.

3. Generation controls and cost

The model predicts likely continuations, so outputs can vary. temperature ranges from low randomness to high randomness; lower values are useful for stable classification or support answers, while higher values can help brainstorming. max_completion_tokens limits the maximum generated output. Input and output tokens are counted in the response usage metadata and determine API cost.

response = client.chat.completions.create(
    model="gpt-4o-mini",
    temperature=0.2,
    max_completion_tokens=120,
    messages=[
        {"role": "user", "content": "Write a concise product description for a fitness smartwatch."}
    ]
)

print(response.choices[0].message.content)
print(response.usage.prompt_tokens)
print(response.usage.completion_tokens)
Common trap: max_completion_tokens is a ceiling, not a promise that every answer will use that many tokens. Raising it can increase the possible cost, but the model may stop earlier.

4. Shot prompting

Examples inside the prompt teach the model the desired mapping and format. Zero-shot uses only an instruction. One-shot adds one example. Few-shot adds multiple examples, which often improves consistency for classification, sentiment scoring, and data extraction.

Approach Examples included Best use
Zero-shot None Simple tasks where the instruction and output format are already obvious
One-shot / Few-shot One or several Tasks requiring consistent labels, scoring rules, or exact formatting

5. Worked Example

This few-shot prompt classifies animal habitats and demonstrates the exact pattern used in the chapter: examples first, then new items to complete.

prompt = """Classify each animal as Land, Sea, or Both.
Return only the category.

Zebra = Land
Crocodile = Both
Dolphin = Sea

Salmon =
Frog =
Elephant ="""

response = client.chat.completions.create(
    model="gpt-4o-mini",
    temperature=0,
    messages=[{"role": "user", "content": prompt}]
)

print(response.choices[0].message.content)
Result: The examples define both the categories and the desired equals-sign format, making the model less likely to add unwanted explanations.

6. Validation and Troubleshooting

  • Print the completed prompt before sending it when using an f-string; confirm the inserted text appears in the right place.
  • Check that the instruction states the desired output format, such as bullets, a number, or a category only.
  • Use a low temperature for repeatable classification and scoring tasks; use a higher value only when variety is useful.
  • Inspect response.usage.prompt_tokens and response.usage.completion_tokens when measuring usage.
Red flag: Do not assume a model will follow an unstated format. If you need only a number, category, or fixed structure, say so and provide examples.

7. Common Mistakes

Giving a vague instruction Specify the task, target audience, tone, length, and format. “Write marketing copy” leaves far more room for guessing than a precise request.
Confusing tokens with words Tokens are model-processing units made from characters or parts of words. A 100-token limit is not exactly 100 words.
Using high randomness for classification For stable labels or sentiment scores, use a low temperature and show examples of the required output.

8. Interview Translation

How do zero-shot, one-shot, and few-shot prompting differ? Zero-shot provides an instruction only. One-shot adds one example. Few-shot adds several examples to teach the expected mapping, tone, or output format.
What does temperature control? It influences randomness in token selection. Lower values generally make responses more consistent; higher values permit more variation and creativity.
How do you control and monitor response size and cost? Set max_completion_tokens as an output ceiling, then inspect the response usage fields for actual input and output token counts. Cost depends on the model's current token prices.
