1. Create the client

Use the environment variable rather than embedding the key.

from openai import OpenAI

client = OpenAI()
Trap: Do not commit a real key.

2. Basic request

Send one user message and extract the first reply.

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {"role": "user", "content": "Explain APIs simply."}
    ]
)

reply = response.choices[0].message.content
Trap: messages must be a list.

3. System and user roles

Separate behavior from the actual task.

messages = [
    {"role": "system", "content": "Answer like a patient tutor."},
    {"role": "user", "content": "Explain Python lists."}
]
Trap: Do not swap the roles.

4. F-string prompt

Insert source text into the prompt.

prompt = f"""
Summarize this in one sentence:

{customer_chat}
"""
Trap: The f prefix is required.

5. Temperature and length

Control variation and output ceiling.

response = client.chat.completions.create(
    model="gpt-4o-mini",
    temperature=0.2,
    max_completion_tokens=150,
    messages=messages
)
Trap: The output can still be cut off.

6. Token usage

Inspect actual request and response size.

print(response.usage.prompt_tokens)
print(response.usage.completion_tokens)
print(response.usage.total_tokens)
Trap: Tokens are not equivalent to words.

7. Few-shot prompting

Teach labels or format with examples.

prompt = """
Love these! = 5
Comfortable, but not very pretty = 2

Shoes fell apart on second use. =
"""
Trap: Examples must be accurate.

8. Assistant example

Represent example answers as assistant messages.

messages = [
    {"role": "user", "content": "Summarize Portugal."},
    {"role": "assistant", "content": "Portugal borders Spain. Its capital is Lisbon."},
    {"role": "user", "content": "Summarize Greece."}
]
Trap: Example answers do not use role=user.

9. Guardrail

Define scope and refusal behavior.

{
    "role": "system",
    "content": (
        "You are a Python tutor. "
        "Answer only Python questions. "
        "Politely refuse unrelated topics."
    )
}
Trap: A role alone is not a full guardrail.

10. Multi-turn history

Append user, call API, append assistant.

messages.append({"role": "user", "content": user_text})

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=messages
)

reply = response.choices[0].message.content or ""
messages.append({"role": "assistant", "content": reply})
Trap: The API does not remember automatically.

11. Truncation protection

Reject incomplete replies.

choice = response.choices[0]

if choice.finish_reason == "length":
    raise RuntimeError("Reply was truncated.")
Trap: Do not append truncated output.

12. Snapshot history

Persist the full conversation after each call.

json_path.write_text(
    json.dumps(payload, indent=2, ensure_ascii=False),
    encoding="utf-8"
)
Trap: Snapshots may contain sensitive user data.
