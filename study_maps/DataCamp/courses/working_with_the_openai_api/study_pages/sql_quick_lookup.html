Client and Basic Requests

Create the client

Create a client that reads OPENAI_API_KEY from the environment

from openai import OpenAI

client = OpenAI()
Do not hard-code a real API key.

Basic chat request

Send one user message to a selected model

response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "Explain APIs simply."}]
)
messages must be a list of dictionaries.

Extract generated text

Read the first generated assistant message

reply = response.choices[0].message.content
print(reply)
The whole response object is not the same as the text.

Prompting and Output Controls

F-string prompt

Insert source text into a readable prompt

prompt = f"""
Summarize this:

{customer_chat}
"""
The f prefix is required.

Temperature

Control consistency versus variation

temperature=0.2
Higher values may increase drift.

Completion limit

Cap generated output

max_completion_tokens=150
A low ceiling can cut off the answer.

Tokens and Prompting Patterns

Inspect token usage

Measure input, output, and total tokens

print(response.usage.prompt_tokens)
print(response.usage.completion_tokens)
print(response.usage.total_tokens)
Tokens are not the same as words.

Few-shot prompt

Teach labels or output format through examples

Love these! = 5
Comfortable, but not very pretty = 2
Shoes fell apart on second use. =
Poor examples teach poor output.

Assistant example

Demonstrate the desired answer pattern

{"role": "user", "content": "Summarize Portugal."},
{"role": "assistant", "content": "Portugal borders Spain. Its capital is Lisbon."}
Example question is user; example answer is assistant.

Roles, Guardrails, and Conversation Memory

System guardrail

Define role, scope, and refusal behavior

{"role": "system", "content": "Answer only Python questions. Politely refuse others."}
A role alone is weaker than an explicit scope.

Append a conversation turn

Store the newest user and assistant messages

messages.append({"role": "user", "content": user_text})
messages.append({"role": "assistant", "content": reply})
The API does not append history for you.

Protect against truncation

Check why generation stopped before saving the reply

if response.choices[0].finish_reason == "length":
    raise RuntimeError("Reply was truncated")
Do not append an incomplete reply.

Course Request Flow

OpenAI() ↓ messages list ↓ chat.completions.create() ↓ response.choices[0].message.content ↓ print/use reply or append it to history
For multi-turn conversations, input tokens grow because each call resends the stored history. Check finish_reason before saving a reply.
