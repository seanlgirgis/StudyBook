1. How to Use This Test

Target: 20 or more correct without reference material before moving on.

2. Self-Test

1. [Concept] What does the system role control?

Answer: Behavior, tone, scope, and guardrails.

2. [Concept] Where is the actual human request stored?

Answer: In a message with role=user.

3. [Concept] What is the assistant role?

Answer: A label for model replies or example answers.

4. [Concept] Why does input-token usage grow in a multi-turn chat?

Answer: Because the full stored conversation history is resent.

5. [Concept] What does temperature control?

Answer: The degree of variation/randomness in generation.

6. [Concept] What does max_completion_tokens control?

Answer: The maximum generated output size.

7. [Concept] What does finish_reason='length' indicate?

Answer: The reply hit the output ceiling and may be truncated.

8. [Concept] What is few-shot prompting?

Answer: Providing one or more examples to guide output.

9. [Concept] Why are poor examples dangerous?

Answer: The model can imitate their errors, style, and bad assumptions.

10. [Concept] Who owns conversation memory?

Answer: The application, not the API.

11. [Code] Complete the extraction path: response.____[0].message.____

Answer: choices and content.

12. [Code] What must surround a message dictionary?

Answer: A list, because messages expects a list of dictionaries.

13. [Code] Which line stores a model reply into history?

Answer: messages.append({'role':'assistant','content':reply})

14. [Code] How do you load a key safely in the basic client?

Answer: Set OPENAI_API_KEY in the environment, then call OpenAI().

15. [Code] What must be added before {customer_chat} is interpolated?

Answer: The f prefix on the string.

16. [Code] Which usage field reports input tokens?

Answer: response.usage.prompt_tokens

17. [Code] Which usage field reports output tokens?

Answer: response.usage.completion_tokens

18. [Code] Which role should hold a worked example answer?

Answer: assistant

19. [Debug] A behavior instruction was placed under role=user. What is wrong?

Answer: It should normally be a system instruction.

20. [Debug] A follow-up ignores the earlier answer. What is the likely problem?

Answer: The prior user/assistant history was not resent.

21. [Debug] A product description invents features. What can help?

Answer: Lower temperature and an explicit 'use only confirmed features' instruction.

22. [Debug] A reply ends mid-sentence. What should you inspect?

Answer: finish_reason and max_completion_tokens.

23. [Debug] The next turn used a truncated reply as context. What should change?

Answer: Do not append replies whose finish_reason is length.

24. [Build] Build a request that asks for a two-sentence beginner explanation of APIs.

Answer: Use system for teaching style, user for the task, and a small completion limit.

25. [Build] Build a two-turn chat where the second question refers to the first answer.

Answer: Append user, call API, append assistant, then append the follow-up and resend the whole messages list.
