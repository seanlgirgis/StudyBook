Prompt Foundations

System + user roles

Separate lasting behavior from the current request.

messages = [
  {"role": "system", "content": system_prompt},
  {"role": "user", "content": user_prompt}
]
Do not place one-turn user data into the persistent system contract unless intended.

Delimited source text

Separate instructions from the text to transform.

prompt = f"""Summarize this text:
```{text}```"""
Delimiters improve clarity; they do not guarantee resistance to prompt injection.

Explicit constraints

Make the response measurable and testable.

Use exactly 3 bullets.
Return only the labels.
Keep under 80 words.
Conflicting or excessive constraints can reduce quality.

Examples and Task Control

Zero-shot

Give instructions without examples.

Classify as Positive, Negative, or Neutral.
Return only the label.
The model may choose an unexpected format unless the contract is explicit.

One-shot

Demonstrate one desired input/output pattern.

Input: {1, 3, 4}
Output: [1, 3]
Input: {5, 8, 9}
Output:
One example may not cover edge cases or all categories.

Few-shot

Provide several representative examples.

User: Excellent service.
Assistant: Positive
User: Delivery was late.
Assistant: Negative
Use consistent labels and include representative classes.

Structured Output and Validation

Multi-step task

Define dependent stages in order.

Step 1: identify the issue.
Step 2: infer the likely trigger.
Step 3: recommend the first action.
Several independent fields are not necessarily a multi-step task.

Structured JSON output

Produce machine-readable fields.

Return valid JSON only.
Use null when missing.
Do not add extra keys.
Valid JSON can still contain wrong values.

Python validation

Accept or reject model output deterministically.

data = json.loads(response)
if set(data) != expected_keys:
    raise ValueError("Unexpected keys")
Validate keys, types, allowed values, ranges, and source fidelity.

Chatbot Context and State

Domain fallback

Control out-of-scope chatbot requests.

If outside personal finance, reply exactly:
"Sorry, I only answer personal-finance questions."
Prompt rules improve compliance but do not guarantee it.

Trusted context

Ground an answer in supplied information.

Use only the context below.
If absent, say: "I do not have that information."
The model may still strengthen wording or add unsupported implications.

Structured chat state

Carry compact state across turns.

{
 "confirmed_facts": [],
 "recommended_actions": [],
 "completed_actions": [],
 "open_questions": []
}
Do not let advice become a confirmed fact; validate updates before storage.

Prompt Selection Map

No example needed → zero-shot One format demonstration → one-shot Several classes or edge cases → few-shot Dependent stages → multi-step Machine-facing result → JSON + validation Stateful chat → recent turns + structured state
The prompt controls what the model should return. Deterministic application code controls whether the result is accepted.
