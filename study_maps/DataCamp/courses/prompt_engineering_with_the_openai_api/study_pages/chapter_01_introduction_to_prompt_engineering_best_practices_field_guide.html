1. Big Picture

Prompt engineering is the practice of designing instructions that guide a large language model toward a useful, predictable response. The model does not infer every unstated requirement reliably, so prompt quality depends on making the task, context, audience, constraints, and desired output explicit. The chapter moves from API basics to a repeatable prompt-building method.

Goal ↓ Choose a clear action verb ↓ Add context, audience, and constraints ↓ Separate instructions from input with delimiters ↓ Specify the required output structure ↓ Add conditions when different inputs need different behavior ↓ Call get_response(prompt) and inspect the result ↓ Refine the prompt

2. Prompt Engineering and Message Roles

Prompt engineering means crafting prompts or instructions to obtain a desired response from an LLM. In the OpenAI chat pattern, a system message supplies guiding behavior, a user message contains the current request, and assistant messages represent prior or generated responses. The chapter uses temperature 0 for more deterministic outputs while refining prompts.

from openai import OpenAI

client = OpenAI(api_key="<OPENAI_API_TOKEN>")

def get_response(prompt):
    response = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": prompt}],
        temperature=0
    )
    return response.choices[0].message.content

print(get_response("Explain prompt engineering to a five-year-old."))
What to notice: The API plumbing stays the same while the prompt changes. This isolates prompt quality as the variable being tested.
Important distinction: client.chat.completions.create(...) is the OpenAI SDK call. get_response() is a helper function created by DataCamp or by our local support layer to hide repeated request and response-extraction code.

3. Clear, Specific, and Delimited Prompts

Use verbs that name an observable task, such as write, explain, summarize, describe, compare, or evaluate. Then specify context, audience, length, format, and style. When a prompt contains both instructions and source material, place instructions first and wrap the source material in clear delimiters such as triple backticks. Python f-strings make it easy to insert long input text without manually rebuilding the prompt.

text = """
Golden Retrievers are intelligent, friendly, and highly social dogs.
They often do well in active families and enjoy training.
"""

prompt = f"""
Summarize the text below in no more than two sentences for a family
considering its first dog.

Text:
```{text}```
"""

response = get_response(prompt)
Common trap: Words such as “think about,” “try,” or “tell me about” can leave the task too broad. Replace them with a concrete action and measurable constraints.

4. Structured Outputs and Conditional Logic

The model does not automatically know whether you want a table, bullet list, paragraph with headings, or custom template. State the exact format and required fields. Conditional prompts add simple branching rules, such as generating a title only when the input is in English or contains a required keyword.

Need Prompt instruction Main risk
Structured output “Return a Markdown table with Title and Rating columns.” Unspecified columns or inconsistent formatting.
Conditional behavior “If the text is English and contains technology, suggest a title; otherwise return the required fallback.” Overlapping conditions or vague fallback responses.

5. Worked Example

This prompt combines the chapter’s main ideas: a direct action verb, delimited input, an explicit table schema, a row limit, and a conditional fallback.

product_text = """
A compact solar charger designed for hikers. It weighs 12 ounces,
charges two USB devices, and is water resistant.
"""

prompt = f"""
Analyze the product description delimited by triple backticks.

If the text describes a physical product, return a Markdown table
with exactly these columns: Feature, Evidence, Customer Benefit.
Use no more than three rows.
Otherwise, return exactly: Not a product description.

```{product_text}```
"""

print(get_response(prompt))
Result: The model has a clear task, bounded input, fixed columns, a row limit, and an explicit alternative response. That makes the result easier to validate and reuse.

6. Validation and Troubleshooting

  • Check that the response performs the requested action rather than merely discussing the topic.
  • Verify that all requested fields, headings, columns, or list rules are present.
  • Test at least one normal input and one input that should trigger each conditional fallback.
  • Keep temperature low while testing prompt wording so random variation does not hide whether the instruction improved.
Red flag: A fluent answer is not automatically a correct answer. If the response ignores the format, length, condition, or audience, the prompt still needs refinement.

7. Common Mistakes

Using an ambiguous task verb Replace “think about deforestation” with a concrete request such as “Propose three strategies to reduce deforestation and explain one trade-off for each.”
Mixing instructions and source text together Put instructions first, label the input, and wrap the input in delimiters. This helps the model distinguish what to do from what to process.
Relying only on max_tokens for response length A strict token cap can cut an answer off. Also state the intended number of words, sentences, paragraphs, rows, or bullets inside the prompt.

8. Interview Translation

What makes a prompt effective? An effective prompt states a clear task, supplies relevant context, defines constraints and audience, separates source material with delimiters, and specifies a verifiable output format.
Why use delimiters in prompts? Delimiters mark the boundary between instructions and input data. This improves readability, reduces ambiguity, and makes variable input safer to insert with an f-string.
When would you use a conditional prompt? Use one when the desired response depends on properties of the input. State each condition, the action for a match, and an exact fallback for non-matching input.
