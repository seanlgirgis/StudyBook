1. Big Picture

Aggregate functions compress many input rows into one summary result. They help answer questions such as total revenue, average film duration, highest score, lowest budget, or number of known values.

Many rows ↓ Aggregate function ↓ One summary value
Core idea: aggregates summarize a set of rows. WHERE controls which rows enter that set.

2. Core Aggregate Functions

Function Purpose Example
COUNT() Count rows or known values COUNT(*)
SUM() Add numeric values SUM(gross)
AVG() Calculate an arithmetic mean AVG(duration)
MIN() Return the smallest value MIN(release_year)
MAX() Return the largest value MAX(imdb_score) 
SELECT AVG(duration) AS average_duration,
       MIN(duration) AS shortest_duration,
       MAX(duration) AS longest_duration
FROM films;
Multiple aggregate expressions can appear in the same SELECT because each summarizes the same input set.

3. Aggregate Functions and Data Types

Aggregate functions have data-type requirements.

Numeric-friendly

SUM and AVG require numeric input.

Broader comparison

MIN and MAX can work with numbers, dates, and often text.

Counting

COUNT can count rows, values, expressions, or distinct values.

Returned type

The result type depends on the function and input data type.

SELECT MIN(title) AS alphabetically_first_title,
       MAX(title) AS alphabetically_last_title
FROM films;
Text MIN and MAX follow the database's collation and sorting rules.

Useful extension: cast text before numeric aggregation

If a value is conceptually numeric but stored as text, cast it before using numeric comparisons or aggregation. 

SELECT MIN(year_text::integer) AS earliest_year,
       MAX(year_text::integer) AS latest_year
FROM your_table;

The standard SQL form is:

SELECT MIN(CAST(year_text AS integer)) AS earliest_year,
       MAX(CAST(year_text AS integer)) AS latest_year
FROM your_table;
Do not cast dirty text blindly. Values such as 'Unknown', an empty string, or '202A' will cause the cast to fail. 
SELECT MAX(
         CASE
           WHEN year_text ~ '^\d{4}$'
           THEN year_text::integer
         END
       ) AS latest_valid_year
FROM your_table;
Memory rule: text MIN/MAX use lexical ordering; numeric MIN/MAX use numeric ordering.

4. Summarizing Subsets with WHERE

WHERE filters rows before the aggregate function summarizes them. 

SELECT AVG(imdb_score) AS average_canadian_score
FROM films
WHERE country = 'Canada';
SELECT SUM(gross) AS total_recent_gross
FROM films
WHERE release_year >= 2020;
SELECT MAX(budget) AS largest_action_budget
FROM films
WHERE genre = 'Action';
FROM films ↓ WHERE country = 'Canada' ↓ AVG(imdb_score) ↓ One result
Execution rule: filter first, aggregate second.

5. Rounding Results with ROUND()

ROUND() changes the displayed numeric precision.

Round to the nearest whole number

SELECT ROUND(AVG(duration)) AS rounded_average_duration
FROM films;

Round to two decimal places

SELECT ROUND(AVG(imdb_score), 2) AS average_score
FROM films;
In PostgreSQL, the two-argument form of ROUND(value, places) is most naturally used with NUMERIC. Some expressions may need a cast. 
SELECT ROUND(AVG(duration)::numeric, 2) AS average_duration
FROM films;

6. ROUND() with a Negative Parameter

A negative second argument rounds to positions left of the decimal point.

Expression Meaning Example result
ROUND(12345, -1) Nearest ten 12350
ROUND(12345, -2) Nearest hundred 12300
ROUND(12345, -3) Nearest thousand 12000 
SELECT ROUND(AVG(budget), -3)
       AS avg_budget_rounded_to_thousands
FROM films;
Positive places move right of the decimal; negative places move left. In the local lab, this returned 21033000, which is the average known budget rounded to the nearest thousand.

7. Arithmetic in SQL

Operator Meaning
+Addition
-Subtraction
*Multiplication
/Division
%Remainder/modulo

Calculate profit

SELECT title,
       gross - budget AS profit
FROM films;

Calculate a percentage

SELECT title,
       ROUND((gross / NULLIF(budget, 0)) * 100, 2)
         AS gross_as_percent_of_budget
FROM films;
Integer division may discard the fractional portion. Use a decimal or cast when a precise ratio is required. 
SELECT 5 / 2;          -- integer result in PostgreSQL
SELECT 5.0 / 2;        -- decimal result
SELECT 5::numeric / 2; -- decimal result
Arithmetic involving NULL returns NULL. Division by zero raises an error; NULLIF(denominator, 0) can safely turn a zero denominator into NULL.

8. Aliasing Aggregate and Arithmetic Results

Calculated expressions should usually have clear aliases. 

SELECT AVG(duration) AS average_duration,
       SUM(gross) AS total_gross,
       MAX(imdb_score) AS highest_score
FROM films;
SELECT title,
       gross - budget AS profit
FROM films;
Memory rule: aliases make output understandable, but they do not rename stored columns.

9. Aggregate Functions and NULL

Most aggregate functions ignore NULL values. 

SELECT COUNT(*) AS total_films,
       COUNT(budget) AS known_budgets,
       AVG(budget) AS average_known_budget
FROM films;

The average uses only rows where budget is not NULL.

This can be correct or misleading depending on the question. Always know whether missing values were excluded from the calculation.
Function Typical NULL behavior
COUNT(*)Counts all rows
COUNT(column)Ignores NULL
SUM(column)Ignores NULL
AVG(column)Ignores NULL
MIN(column)Ignores NULL
MAX(column)Ignores NULL

10. Common Mistakes

Assuming AVG includes NULL as zero It does not. NULL values are excluded from both the sum and the count used by the average.
Forgetting to alias a calculated expression The query still works, but the result column may be difficult to understand.
Using SUM or AVG on text These functions require numeric-compatible input.
Rounding too early Perform the full calculation first, then round the final result unless the business rule says otherwise.
Unexpected integer division Cast or use a decimal operand when the fractional result matters.
Ignoring division by zero Protect denominators with NULLIF(value, 0) when zero is possible.

11. Interview Translation

What is an aggregate function? It summarizes a set of rows into a single value, such as a count, sum, average, minimum, or maximum.
How does WHERE interact with aggregates? WHERE filters the source rows before the aggregate function calculates its result.
How does AVG handle NULL? It ignores NULL values and divides the sum of known values by the count of known values.
What does ROUND(value, -2) do? It rounds the value to the nearest hundred.
Why alias an aggregate expression? A meaningful alias makes the result self-explanatory for reports, downstream queries, and reviewers.
How do you avoid integer division? Cast one operand to a decimal type or use a decimal literal before dividing.
