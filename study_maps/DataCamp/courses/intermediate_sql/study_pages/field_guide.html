2. Selecting Data

SELECT and FROM

SELECT chooses output columns. FROM chooses the source table.

DISTINCT

Removes duplicate result rows based on the complete selected column set.

COUNT(*)

Counts rows, including rows that contain NULL in individual columns.

COUNT(column)

Counts only non-NULL values in the selected column or expression.

COUNT(DISTINCT column)

Counts unique non-NULL values.

PostgreSQL FILTER

Performs concise conditional aggregation.

SELECT COUNT(*) AS total_films,
       COUNT(budget) AS known_budgets,
       COUNT(DISTINCT country) AS country_count
FROM films;
Local evidence: 16 rows, 15 known budgets, and 10 distinct countries.

3. Filtering Records

AND

Every condition must be true. It usually narrows the result.

OR

At least one condition must be true. It usually broadens the result.

SELECT title,
       country,
       release_year
FROM films
WHERE (country = 'Canada' OR country = 'Germany')
  AND release_year >= 2019;
Pattern Purpose Key trap
BETWEENInclusive rangeBoth endpoints are included
LIKEPattern matching% and _ are wildcards
ILIKECase-insensitive PostgreSQL pattern matchingPostgreSQL-specific
INMatch a listCleaner than repeated OR conditions
IS NULLFind missing valuesDo not use = NULL

4. Aggregate Functions

Function Purpose
COUNTCount rows or known values
SUMAdd numeric values
AVGCalculate the arithmetic mean
MINReturn the smallest value
MAXReturn the largest value
 
SELECT ROUND(AVG(duration), 2) AS average_duration,
       SUM(gross) AS total_gross,
       MAX(imdb_score) AS highest_score
FROM films;

Rounding left of the decimal

SELECT ROUND(AVG(budget), -3)
       AS avg_budget_rounded_to_thousands
FROM films;
Positive precision rounds to decimal places. Negative precision rounds to tens, hundreds, thousands, and larger positions.

Arithmetic and safe division

SELECT title,
       gross - budget AS profit,
       ROUND((gross / NULLIF(budget, 0)) * 100, 2)
         AS gross_as_percent_of_budget
FROM films;
PostgreSQL integer division truncates the fractional portion: 5 / 2 = 2, while 5.0 / 2 = 2.5.

5. Sorting and Grouping

Multi-column sorting

SELECT title,
       release_year,
       imdb_score
FROM films
ORDER BY release_year ASC,
         imdb_score DESC;

SQL sorts by the first expression, then uses later expressions as tie-breakers.

Grouped summaries

SELECT country,
       COUNT(*) AS film_count
FROM films
GROUP BY country
ORDER BY film_count DESC,
         country ASC;

WHERE versus HAVING

WHERE

Filters individual rows before grouping.

HAVING

Filters completed groups after aggregation.

SELECT country,
       COUNT(*) AS recent_film_count
FROM films
WHERE release_year >= 2019
GROUP BY country
HAVING COUNT(*) >= 2
ORDER BY recent_film_count DESC,
         country;
Every selected non-aggregate expression must appear in GROUP BY.

6. Logical Query Execution Order

1. FROM 2. WHERE 3. GROUP BY 4. HAVING 5. SELECT 6. DISTINCT 7. ORDER BY 8. LIMIT
This order explains why row filters belong in WHERE, aggregate filters belong in HAVING, and selected aliases can often be used in ORDER BY.

7. Common Mistakes

Using COUNT(column) as a total row count It ignores NULL values. Use COUNT(*) for total rows.
Using = NULL Use IS NULL or IS NOT NULL.
Mixing AND and OR without parentheses Parentheses make the intended condition grouping explicit.
Using WHERE with aggregate conditions Use HAVING after grouping.
Unexpected integer division Cast one operand or use a decimal literal.
Assuming rows are naturally ordered Use ORDER BY whenever output order matters.

8. Interview Translation

COUNT(*) versus COUNT(column) COUNT(*) counts rows. COUNT(column) counts only non-NULL values.
WHERE versus HAVING WHERE filters rows before grouping; HAVING filters grouped results.
ORDER BY versus GROUP BY ORDER BY changes result order; GROUP BY changes result granularity.
Why logical execution order matters It explains when rows, groups, aliases, sorting, and limits become available.
How aggregates handle NULL Most ignore NULL values; COUNT(*) counts rows regardless of individual NULL fields.
