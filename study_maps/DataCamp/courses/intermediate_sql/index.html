Chapter 1 — Selecting Data

SELECT, FROM, DISTINCT, COUNT forms, query execution, debugging, SQL style, and identifier handling.

COUNT, SUM, AVG, MIN, MAX, ROUND, arithmetic, aliases, integer division, NULLIF, and casting.

Chapter 4 — Sorting and Grouping

ORDER BY, GROUP BY, HAVING, multi-column sorting, grouped summaries, and full execution order.
