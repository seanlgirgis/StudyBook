Database Structure

Database, Table, Row, Column

Use these words precisely.

TermMeaning
DatabaseOrganized collection of related data
TableRows and columns about one main subject
Row / recordOne item or observation
Column / fieldOne attribute stored for every row
Row = one thing. Column = one attribute.

Unique Identifier / Key

A stable value that distinguishes one row.

Use keys to identify rows and connect tables.
Do not rely on a person’s name as a unique ID.

Common Data Types

NeedType

Choose by meaning, not appearance.

Schema

The structural blueprint of a database.

Schema = tables + columns + types + relationships.

Basic Query Patterns

Select One Column

SELECT title
FROM books;
SELECT chooses columns; FROM chooses the table.

Select Multiple Columns

SELECT title, author, pub_year
FROM books;
Separate columns with commas.

Select All Columns

SELECT *
FROM books;
Good for exploration; avoid it in reusable production queries.

Readable SQL Style

SELECT title,
       author,
       pub_year
FROM books;
Uppercase keywords, separate clauses, end with a semicolon.

Useful Modifiers

Unique Values

SELECT DISTINCT genre
FROM books;
With multiple columns, DISTINCT returns unique combinations.

Alias a Column

SELECT name AS patron_name
FROM patrons;
AS changes the result label, not the stored column.

Create a View

CREATE VIEW patron_names AS
SELECT card_num,
       name
FROM patrons;
A view is a named saved query.

Query a View

SELECT *
FROM patron_names;

SQL Flavor Differences

PostgreSQL: Limit Rows

SELECT title
FROM books
LIMIT 5;

SQL Server: Limit Rows

SELECT TOP 5 title
FROM books;

SQL Flavor / Dialect

A database-specific variation of SQL.

Core SQL transfers well; some functions and syntax differ.

Limiting Without Ordering

LIMIT or TOP restricts row count.

Without ORDER BY, “first” rows are not guaranteed to be meaningful.

Fast Interview Answers

Relational Database

Stores structured data in tables and connects those tables through shared keys.

SELECT

Specifies which columns or expressions appear in the query result.

DISTINCT

Removes duplicate result rows based on all selected columns.

View

A named saved query used to simplify or reuse data-access logic.
