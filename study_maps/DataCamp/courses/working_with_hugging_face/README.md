This course covers:

- text classification;
- zero-shot classification;
- QNLI;
- summarization;
- `AutoTokenizer`;
- `AutoModelForSequenceClassification`;
- logits and `argmax()`;
- PDF extraction with PyPDF;
- extractive document question answering;
- confidence-threshold rejection.
