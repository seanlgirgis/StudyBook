1. Pipelines and Basic Inference

Sentiment Classification

A pipeline bundles tokenization, model inference, and output formatting. The selected model defines the labels.

from transformers import pipeline

classifier = pipeline(
    "sentiment-analysis",
    model="distilbert/distilbert-base-uncased-finetuned-sst-2-english"
)

result = classifier("I really enjoy this course.")
print(result)
What to remember: Output is usually a list of dictionaries containing a label and score.

Text Generation

Text generation continues a prompt. max_new_tokens limits newly generated tokens; num_return_sequences controls how many alternatives are returned.

from transformers import pipeline

generator = pipeline(
    task="text-generation",
    model="openai-community/gpt2"
)

results = generator(
    "What if AI",
    max_new_tokens=10,
    num_return_sequences=2
)

for result in results:
    print(result["generated_text"])
What to remember: Generated output is structured data, not a plain string.

2. Model Selection and Hosted Inference

Explicit Model Selection

Naming the model makes the code reproducible and prevents silent dependence on a changing default.

classifier = pipeline(
    "text-classification",
    model="distilbert/distilbert-base-uncased-finetuned-sst-2-english"
)
What to remember: Check the model card for task, language, license, training data, limitations, and size.

Hosted Inference Client

Hosted inference runs the model on remote provider hardware instead of the local machine.

import os
from huggingface_hub import InferenceClient

client = InferenceClient(
    provider="together",
    api_key=os.environ["HF_TOKEN"]
)
What to remember: Hosted inference trades local hardware requirements for network, cost, privacy, and provider dependence.

3. Hugging Face Datasets

Load a Dataset Split

load_dataset() downloads or opens a named dataset and returns a Hugging Face Dataset object.

from datasets import load_dataset

dataset = load_dataset(
    "TIGER-Lab/MMLU-Pro",
    split="validation"
)

print(dataset)
What to remember: A split is a named portion such as train, validation, or test.

Shuffle, Select, and Filter

shuffle() creates a reproducible random order, select() keeps row positions, and filter() keeps rows matching a condition.

dataset = load_dataset("imdb", split="train")

sample = dataset.shuffle(seed=42).select(range(20))

positive_rows = sample.filter(
    lambda row: row["label"] == 1
)

print("Positive rows:", len(positive_rows))
What to remember: filter() is closest to SQL WHERE. Do not assume the first rows are representative.

4. Tokenization and Tensors

Inspect Token Pieces

tokenize() shows text pieces. Subword markers such as ## indicate continuation pieces.

from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained(
    "distilbert-base-uncased-finetuned-sst-2-english"
)

tokens = tokenizer.tokenize(
    "AI: Making robots smarter and humans lazier!"
)

print(tokens)
What to remember: The same word may split differently under different tokenizers.

Create PyTorch Tensors

return_tensors='pt' converts tokenizer output into PyTorch tensors for model input.

encoded = tokenizer(
    "I like to visit the park on sunny days.",
    return_tensors="pt"
)

print(encoded["input_ids"])
print(encoded["attention_mask"])
What to remember: input_ids are token numbers. attention_mask uses 1 for real tokens and 0 for padding.

5. AutoClasses and Raw Model Output

AutoModel + AutoTokenizer

AutoClasses load the correct architecture and tokenizer for a model repository.

import torch
from transformers import (
    AutoModelForSequenceClassification,
    AutoTokenizer
)

model_name = (
    "distilbert/distilbert-base-uncased-"
    "finetuned-sst-2-english"
)

tokenizer = AutoTokenizer.from_pretrained(model_name)
model = AutoModelForSequenceClassification.from_pretrained(model_name)

inputs = tokenizer(
    "I really enjoy learning Hugging Face.",
    return_tensors="pt"
)

with torch.no_grad():
    outputs = model(**inputs)

predicted_id = outputs.logits.argmax(dim=-1).item()
label = model.config.id2label[predicted_id]

print(label)
What to remember: logits are raw model scores. argmax() selects the highest-scoring class.

AutoClasses Inside a Pipeline

You can explicitly load model and tokenizer objects, then still use pipeline() for simple inference.

from transformers import pipeline

my_pipeline = pipeline(
    task="sentiment-analysis",
    model=model,
    tokenizer=tokenizer
)

output = my_pipeline(
    "This course is pretty good, I guess."
)

print(output)
What to remember: This combines explicit control with pipeline convenience.

6. Classification Variants

Grammar Classification

The same text-classification workflow can represent a different task when a different trained model is used.

grammar_checker = pipeline(
    task="text-classification",
    model="abdulmatinomotoso/English_Grammar_Checker"
)

print(grammar_checker("I will walk dog"))
print(grammar_checker("I will walk the dog."))
What to remember: Generic labels such as LABEL_0 and LABEL_1 are model-specific.

Zero-Shot Classification

Candidate labels are supplied at runtime rather than being fixed to one business taxonomy.

classifier = pipeline(
    task="zero-shot-classification",
    model="facebook/bart-large-mnli"
)

output = classifier(
    "AI-powered robots assist in complex brain surgeries.",
    candidate_labels=["politics", "science", "sports"]
)

for label, score in zip(
    output["labels"],
    output["scores"]
):
    print(label, score)
What to remember: The model ranks all supplied candidate labels.

QNLI

QNLI judges whether a passage supports answering a question. It does not extract the answer.

qnli = pipeline(
    task="text-classification",
    model="cross-encoder/qnli-electra-base"
)

result = qnli(
    "Where is the capital of France?, "
    "Paris is the capital of France.",
    top_k=None
)

print(result)
What to remember: Use top_k=None when you need to inspect all label scores.

7. Summarization

Summarize Text

Summarization returns a list containing summary_text. Length settings must fit the model and installed Transformers version.

summarizer = pipeline(
    task="summarization",
    model="sshleifer/distilbart-cnn-12-6"
)

summary = summarizer(
    original_text,
    min_length=10,
    max_length=40
)

summary_text = summary[0]["summary_text"]

print(summary_text)
print(len(original_text))
print(len(summary_text))
What to remember: len() counts characters here, not words or tokens. A short summary can omit important qualifications.

8. PDF Extraction and Document Q&A

Extract Text from Every PDF Page

PyPDF reads a PDF text layer. Each page is extracted and appended into one context string.

from pypdf import PdfReader

reader = PdfReader("US_Employee_Policy.pdf")

document_text = ""

for page_number, page in enumerate(
    reader.pages,
    start=1
):
    page_text = page.extract_text() or ""
    document_text += page_text + "\n"
What to remember: Scanned-image PDFs may require OCR because they may not contain a text layer.

Question Answering with Threshold

Extractive Q&A chooses an answer span from context. A confidence threshold prevents weak forced answers from being displayed.

qa = pipeline(
    task="question-answering",
    model="distilbert/distilbert-base-cased-distilled-squad"
)

result = qa(
    question="What is the notice period for resignation?",
    context=document_text
)

if result["score"] < 0.30:
    print("Not enough information in the document.")
else:
    print(result["answer"])
What to remember: A low score can indicate that the context does not contain a reliable answer.
