Pipelines and Classification

Sentiment pipeline

Run a named sentiment model and return label plus score.

classifier = pipeline(
    "sentiment-analysis",
    model=model_name
)
result = classifier(text)
A high score does not prove deep understanding or domain fit.

Grammar classifier

Use a grammar-specific model through the general text-classification workflow.

checker = pipeline(
    "text-classification",
    model="abdulmatinomotoso/English_Grammar_Checker"
)
LABEL_0 and LABEL_1 are model-specific; verify their meanings.

Zero-shot classification

Rank candidate labels supplied at runtime.

result = classifier(
    text,
    candidate_labels=[
        "politics",
        "science",
        "sports"
    ]
)
Label wording changes the result; validate against your business taxonomy.

Datasets and Tokenization

Load a split

Load one named dataset split.

dataset = load_dataset(
    "TIGER-Lab/MMLU-Pro",
    split="validation"
)
Loading a train split does not mean training has started.

Shuffle, select, filter

Create a repeatable sample and keep rows by position or condition.

sample = dataset.shuffle(
    seed=42
).select(range(20))

positive = sample.filter(
    lambda row: row["label"] == 1
)
Do not assume the first rows are random or representative.

Tokenizer tensors

Create input IDs and attention masks as PyTorch tensors.

encoded = tokenizer(
    text,
    return_tensors="pt"
)

print(encoded["input_ids"])
print(encoded["attention_mask"])
The attention mask marks real versus padded positions, not important versus unimportant words.

AutoClasses and Summarization

Load AutoClasses

Load the task model and its paired tokenizer.

tokenizer = AutoTokenizer.from_pretrained(
    model_name
)
model = AutoModelForSequenceClassification.from_pretrained(
    model_name
)
The model must use the tokenizer it was trained with.

Logits to label

Convert raw model scores to a readable prediction.

outputs = model(**inputs)
predicted_id = outputs.logits.argmax(
    dim=-1
).item()
label = model.config.id2label[
    predicted_id
]
Logits are raw scores, not probabilities.

Summarization

Generate a shorter version with explicit output-length limits.

summary = summarizer(
    original_text,
    min_length=10,
    max_length=40
)

text = summary[0]["summary_text"]
A fluent summary may omit qualifications or add unsupported details.

Document Processing and Q&A

Extract PDF text

Combine text from every PDF page.

reader = PdfReader(pdf_path)

document_text = ""
for page in reader.pages:
    document_text += (
        page.extract_text() or ""
    ) + "\n"
Scanned image PDFs may need OCR because they lack a text layer.

Question answering

Extract an answer span from supplied context.

result = qa(
    question=question,
    context=document_text
)
The model may force a best-looking span even when the answer is absent.

Confidence rejection

Return a safe fallback for weak Q&A results.

if result["score"] < 0.30:
    print("Not enough information.")
else:
    print(result["answer"])
A threshold is application-specific and must be validated on representative examples.
