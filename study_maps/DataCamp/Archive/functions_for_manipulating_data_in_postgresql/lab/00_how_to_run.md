# How to Run

## Prerequisites

- PostgreSQL available

## Open psql or SQL client

- Connect to your PostgreSQL instance using `psql` or your preferred SQL client.

## Run SQL files in order

- Run `sql\00_create_schema.sql`
- Run `sql\01_create_tables.sql`
- Run `sql\02_insert_sample_data.sql`
