- SparkSession basics, lazy evaluation, transformations vs actions
- DataFrame operations: select, filter, withColumn, agg, orderBy

## SQL connection
- PySpark DataFrame operations mirror SQL operations conceptually
- explain SQL equivalence for select/filter/join/group/aggregate paths

- shell skills support job orchestration, logs, wrappers, and automation around Spark jobs
- command-line fluency helps with environment checks and operational debugging

## ETL connection
- frame PySpark as extract-transform-load execution engine for batch pipelines
- emphasize data quality checks, idempotence, and reusable transforms

## scheduler/Airflow connection
- Airflow orchestrates Spark jobs with dependencies, retries, and monitoring
- highlight DAG-level control, retry semantics, and operational visibility

## production support language

- communicate issue impact, mitigation, and prevention clearly
