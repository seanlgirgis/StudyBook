PySpark Mental Model

  • Spark is the distributed engine.
  • PySpark is the Python API.
  • Driver coordinates.
  • Executors process partitions.
  • DataFrames express distributed ETL work.
  • Transformations build the plan.
  • Actions trigger execution.

Motherload detail | QA Q01-Q10

SparkSession and DataFrames

  • SparkSession is the entry point.
  • DataFrame is the main table-like distributed object.
  • show(), count(), collect(), and write are actions.
from pyspark.sql import SparkSession

spark = SparkSession.builder.appName("my_spark").getOrCreate()

Reading Data and Schemas

  • CSV, JSON, Parquet.
  • header=True.
  • inferSchema=True.
  • printSchema().
  • manual schema with StructType/StructField.

  • na.drop / na.fill

Joins, Unions, and UDFs

  • joins combine DataFrames by key
  • leftouter enrichment join preserves main records
  • union stacks same-schema DataFrames
  • built-in Spark functions first
  • UDFs only when custom logic is needed
  • pandas UDFs for vectorized custom logic when justified

RDDs and Spark SQL

  • RDDs are Spark's lower-level distributed abstraction.
  • DataFrames are preferred for normal structured ETL.
  • createOrReplaceTempView() registers a temp view.
  • spark.sql() returns a DataFrame.

Aggregations and PySpark at Scale

  • Filter, type, clean, validate before aggregating.
  • explain() shows execution plan.
  • cache/persist only reused DataFrames.
  • unpersist when done.
  • broadcast joins reduce shuffle for small lookup tables.
  • repeated actions trigger repeated jobs.

Production Support Mindset

  • input counts
  • output counts
  • schema checks
  • null checks
  • join row-count checks
  • logs
  • failed stages
  • executor errors
  • parameters
  • upstream/downstream dependencies
  • safe rerun behavior
  • overwrite vs append risk
