# Course 3: Joining Data in SQL - Course Summary

Status: draft summary started

Course 3 covered several ways to combine, compare, and filter relational data.

Major topics:
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- FULL JOIN
- CROSS JOIN
- SELF JOIN
- semi joins
- anti joins
- set operations
  - UNION
  - UNION ALL
  - INTERSECT
  - EXCEPT
- subqueries inside WHERE
- subqueries inside SELECT
- subqueries inside FROM

Big idea:
JOINs usually combine related rows side-by-side.
Set operations stack or compare SELECT results.
Subqueries allow one query to use the result of another query.
