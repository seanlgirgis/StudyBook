# DataCamp Architecture Decisions

- Preserve old content in `DataCamp.old`.
- Rebuild `DataCamp` as a clean canonical root.
- Use `courses/` for reusable course packages.
- Use `projects/` for reusable project packages.
- Use `tracks/` for track playlists and pointers.
- Keep runnable practice under `tutorials\DataCamp`.
- Do not use `Study_bubbles` for course content.
