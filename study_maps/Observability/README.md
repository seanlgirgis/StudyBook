# Cloud Observability Study System

This is Sean's learning product for cloud observability.
It starts with Level 0 across all topics.

## Architecture Law

study_maps\Observability = learning product.
tutorials\Observability = future lab bench only.
Study_bubbles = engine only.

## Level 0 Scope

Level 0 is:
- orientation
- plain-English understanding
- tool landscape
- Sean skill bridge
- safe positioning
- overclaim guardrails
- first interview story
- first StudyBubble map
- completion checklist

Level 0 is NOT:
- Docker
- AWS setup
- OpenTelemetry instrumentation
- Prometheus scraping
- Grafana dashboard building
- Kubernetes cluster setup
- Splunk searches
- Datadog setup
- Dynatrace hands-on setup

## Horizontal Maturity Strategy

We are not taking one tool from Level 0 to Level 10.
We are building Level 0 across all topics, then Level 1 across all topics,
then Level 2 across all topics.
