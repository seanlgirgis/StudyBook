1000-Foot View - What PySpark Is

Mental model: Spark is the distributed engine. PySpark is the Python steering wheel.

Core Concepts

  • Spark: distributed processing engine
  • PySpark: Python API for Spark
  • Driver: coordination process
  • Executors: worker processes
  • SparkSession: entry point
  • DataFrame: distributed tabular structure
  • Transformations: lazy steps
  • Actions: trigger execution
  • Partitions: parallel split units
  • Shuffle: cross-executor data movement

Conceptual Snippet

df = spark.read.csv("input.csv", header=True)
result = df.filter(df.status == "ACTIVE").groupBy("region").count()
result.show()

show() is an action, so execution is triggered there.
