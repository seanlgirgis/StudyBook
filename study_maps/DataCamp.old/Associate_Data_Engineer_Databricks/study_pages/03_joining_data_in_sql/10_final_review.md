# Course 3: Joining Data in SQL - Final Review

Status: draft review started

Fast review:
- INNER JOIN keeps only matching rows.
- LEFT JOIN keeps all rows from the left table.
- RIGHT JOIN keeps all rows from the right table.
- FULL JOIN keeps unmatched rows from both sides.
- CROSS JOIN creates every possible pairing.
- SELF JOIN joins a table to itself using aliases.
- UNION stacks rows and removes duplicates.
- UNION ALL stacks rows and keeps duplicates.
- INTERSECT returns rows common to both SELECT results.
- EXCEPT returns rows in the first SELECT but not the second.
- Semi joins filter for matches using IN.
- Anti joins filter for non-matches using NOT IN.
- WHERE subqueries filter rows.
- SELECT subqueries calculate displayed values.
- FROM subqueries act like temporary tables.
