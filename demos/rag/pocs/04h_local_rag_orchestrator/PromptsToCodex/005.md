Core architecture rule:

The local 8-bit LLM is NOT the final customer-answer model.

The local 8-bit LLM is the primary intention clarification engine.

Its role:
- clean noisy customer input
- extract real service intent
- identify service type
- identify symptoms
- determine urgency
- decide whether clarification is needed
- generate intelligent clarification questions when intent is unclear

Its role is NOT:
- final customer-facing answer generation
- repair instructions
- technician training
- general advice
- hallucinated troubleshooting
- markdown article writing
- freeform reasoning response to customer

Final customer-facing answer is reserved for Grok-3 or another stronger final-answer provider.

Grok-3 must be given:
- original query
- structured cleaned intent from local 8-bit LLM
- retrieved KB sections selected by local code
- strict instruction to answer using only KB sections

- do NOT pretend local 8-bit answer is final production answer
- return/print:
  - structured intent
  - retrieved sections
  - final_answer = null or ""
  - final_provider_used = "unavailable"
  - status = "final_provider_unavailable"
  - note = "Grok final provider unavailable; retrieved sections and intent are ready."
