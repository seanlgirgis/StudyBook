# Memory Rules

1. Always search local files first before answering.
2. Prefer stored local facts over general knowledge.
3. Cite the file path used for the answer.
4. Never invent local usernames, passwords, ports, database names, paths, or commands.
5. If the answer is not stored, say clearly: "I do not have this stored yet."
6. Store new information as question-and-answer entries.
7. Keep entries short, practical, and searchable.
8. Use tags at the bottom of each entry.
